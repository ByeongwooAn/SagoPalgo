# Spring API 서버

- 루트 공통 지침에 이 디렉터리의 규칙을 추가 적용한다.
- 관련 Controller·Service·Mapper·DTO와 대응 테스트부터 읽는다. Java 17과 기존 Gradle 설정을 따른다.
- 계좌·주문은 KB증권, KIS·Toss는 읽기 전용 시장 데이터라는 역할을 유지한다.
- 주문 중복·재시도·체결·잔고·미체결 예약의 상태와 금액 정합성을 보존한다. 불명확한 외부 결과를 성공으로 간주하지 않는다.
- API·SQL 변경은 Flutter/Python 사용처와 DB 마이그레이션·기존 데이터 호환성을 확인한다. 검증을 위해 실주문을 보내지 않는다.
- 명령은 이 폴더에서 실행한다. 개발 중 `.\gradlew.bat test --tests '<관련 테스트 클래스>'`로 확인한다.
- Java 코드 변경 마무리에는 `.\gradlew.bat test`를 실행한다. DB·외부 서비스가 필요한 검증은 프로젝트의 관련 가이드와 실행 조건을 확인한다.
- 컴파일·테스트가 통과하면 패키징·배포 변경이 없는 한 전체 빌드를 추가 반복하지 않는다. 필요한 통합 검증을 실행하지 못하면 보고한다.
