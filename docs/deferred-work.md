## 작업별 필요 근거와 보류 사유

### H05 후속 — 코스피 7종목의 정지·해제 시각

- **필요 근거** — 해당 사건을 분 단위로 재현할 때는 정지 구간에 체결을 가정하거나 해제 전에 주문을 처리하는 오류를 막기 위해 종목별 적용 시각이 필요합니다. KIND 공지에는 시각이 있고 KRX 일자별 이력에는 종목코드와 정지 여부가 있습니다. 두 자료의 날짜 대조로 확인한 범위는 7종목의 일자별 정지 이력입니다. [공지와 일자별 이력 대조](historical-market-action-kospi-halt-records.md#2026-11-15-krx-일자별-정지-이력-대조)
- **보류 사유** — 현재 일봉 데이터 검증은 장중 분 단위 경계를 입력으로 요구하지 않습니다. 영향이 불확실한 종목·날짜는 학습 범위에서 제외하고 근거와 사유를 남긴 뒤, 검증된 표본과 공개 거래소 조치 공지 대조를 이어갈 수 있습니다. 해당 7종목을 장중 재현 범위에 넣을 때 시각을 다시 검토합니다. [5-08 경계 대조와 제외 기준](multi-company-reference-cases.md)

### 5-17 — 상품별 소수점 주문 확장

- **필요 근거** — 소수점 상품을 운용하려면 최소금액·수량 정밀도와 회차별 체결·배분·취소 조건을 상품별로 확인해야 합니다. 중간 반올림은 주문 수량과 원장 대조에 영향을 주고, 회차 처리와 배분 지연은 전략의 진입·청산 시점에 영향을 줍니다. [R9 상품 계약·정밀도·전략](realtime-trading-roadmap.md#r9-소수점-주문배분과-별도-전략)
- **보류 사유** — 현재 우선 범위는 온주입니다. 온주 주문·위험 통제·모의 체결·원장·성과는 기존 정수 수량 계약으로 검증할 수 있습니다. 소수점 주문 경로와 실제 상품 계약 검증은 온주 공통 흐름을 확인한 뒤 소수점 상품을 운용 범위에 넣을 때 재개합니다. [로드맵의 단계별 의존성](realtime-trading-roadmap.md#3-전체-순서와-의존성)

## 관리 기준

- 현재 목표의 완료·안전 검증에 필요한 작업은 실행 목록에서 관리합니다. 거래일, 계약 답변, 실제 계좌나 자료를 기다리는 필수 작업은 선행 조건과 함께 표시합니다.
- 현재 범위의 완료를 가로막지 않는 확장이나 표본의 추가 정밀 검증은 이 문서에 등록합니다. 등록할 때 상위 작업 ID, 작업이 필요한 범위와 근거, 당장 미뤄도 되는 이유, 이미 확인한 결과, 재개·완료 조건을 적습니다.
- [현재 개발 진척도](numbered-work-progress.md#현재-개발-진척도)는 현재 범위의 번호 항목만 계산합니다. 번호 항목 전체를 옮기면 현재 범위의 분모에서 빼고 근거를 기록합니다. 하위 단위만 옮기면 상위 항목은 한 번만 계산합니다. 최초 반영은 5-17 이동으로 48→47개입니다. H05의 7종목은 하위 단위입니다.
- 재개 시 실행 목록에 항목과 선행 조건을 반영하고 이 문서에 이동 날짜를 남깁니다. 번호 항목이 현재 범위로 돌아오면 진척도의 분모를 함께 갱신합니다. 보류 상태에서 완료된 항목은 완료 근거와 날짜를 남겨 이 문서의 완료 건수에 반영합니다.
