## 관리 기준

- 현재 목표의 완료·안전 검증에 필요한 작업은 실행 목록에서 관리합니다. 거래일, 계약 답변, 실제 계좌나 자료를 기다리는 필수 작업은 선행 조건과 함께 표시합니다.
- 현재 범위의 완료를 가로막지 않는 확장이나 표본의 추가 정밀 검증은 이 문서에 등록합니다. 등록할 때 상위 작업 ID, 보류 사유, 이미 확인한 결과, 재개·완료 조건을 적습니다.
- [현재 개발 진척도](numbered-work-progress.md#현재-개발-진척도)는 현재 범위의 번호 항목만 계산합니다. 번호 항목 전체를 옮기면 현재 범위의 분모에서 빼고 근거를 기록합니다. 하위 단위만 옮기면 상위 항목은 한 번만 계산합니다. 최초 반영은 5-17 이동으로 48→47개입니다. H05의 7종목은 하위 단위입니다.
- 재개 시 실행 목록에 항목과 선행 조건을 반영하고 이 문서에 이동 날짜를 남깁니다. 번호 항목이 현재 범위로 돌아오면 진척도의 분모를 함께 갱신합니다. 보류 상태에서 완료된 항목은 완료 근거와 날짜를 남겨 이 문서의 완료 건수에 반영합니다.
