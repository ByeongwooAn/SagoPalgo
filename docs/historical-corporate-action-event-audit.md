# H05 공시·종목 연결과 H04 사건별 근거 대조

H05 후속 감사에서 세이브로 지급일, 소각 상세 원문과 거래소 조치 공지를 추가 대조했습니다. [H05 지급·소각·조치 대조](historical-corporate-action-outcome-census.md)

효력일 범위는 **2023-11-01~2026-11-02 KOSPI·KOSDAQ 보통주**이며, KIND 공시 목록은 **2026-11-07 접수분**까지 포함합니다. 공시일, 종목 관측일, 거래소 조치 적용일, 발행사가 보고한 등기 완료일과 로컬 검토 시각은 각각 별도로 보존합니다.

## H05 공시 목록과 실제 조치

기존 제목 검색 13,786건과 거래소 상세검색의 배당 `0113`, 주식소각 `0131`, 권리락·배당락·기준가격 `0303`, 정지·해제 `0311` 분류를 시장·접수번호로 합쳤습니다. **분류 조회로만 추가된 9,656건**을 포함해 **23,442건**을 대조했습니다. 추가분 중 9,371건은 기준가격 계열, 253건은 배당 계열, 32건은 정지 계열입니다. 기준가격 계열에 ETF 분배락과 신규상장이 섞이고 정지 계열에 신주인수권증권이 포함돼, 후보 수를 보통주 사건 수로 사용하지 않습니다. [KIND 상세검색](https://kind.krx.co.kr/disclosure/details.do?method=searchDetailsMain)

공시일의 시장별 KRX 스냅샷에서 종목 정식명과 당시 거래소 약칭을 대조합니다. 원문 약칭은 당일 원장에 기록된 시장·종목코드·ISIN·정식명이 맞는 경우에만 연결합니다. 같은 이름이 여러 보통주에 걸리거나, 일자가 범위를 벗어나거나, 당시 관측이 없으면 각각 분리합니다. 발행사 표시명이 일치해도 공시 대상이 자회사·우선주·별도 주권일 수 있어, 본문에서 대상을 확인하기 전에는 종목 확정에 사용하지 않습니다.

KIND 주식발행내역의 변경상장·재상장 조회는 양 시장 **1,850행**을 확인했습니다. 이 중 소각 관련 **997행**은 상장일·수량·사유를 별도 경로로 보존했습니다. 삼성전자 2025-03-06 보통주 변경상장 `-50,144,628`주는 기존 공지와 일치합니다. 같은 날의 다른 수량은 분리했고, 실제 소각일 2025-02-20은 원문 공지 근거에 연결했습니다. 나머지 목록 행은 주권 종류와 소각 완료일을 본문에서 대조할 때까지 후보입니다. [KIND 주식발행내역](https://kind.krx.co.kr/corpgeneral/stockissuelist.do?method=loadInitPage) · [삼성전자 공지](https://kind.krx.co.kr/external/2025/02/28/000236/20250228000675/68155.htm)

## H04 당사회사·등기·상장

기존 E003 351건과 KIND 발행실적보고서 68건을 대상으로, 본문의 존속·소멸회사 역할과 단일 기일, KIND 뷰어에서 확인된 문서 버전 묶음, 기존 검토 사건의 직접 접수번호를 사용했습니다. 별도 거래 25건을 분리했고, **공시 여러 건을 묶은 검토 그룹 10개**와 다른 채널에서 발행사·거래 종류·기일이 일치하는 **비교 후보 1개**를 얻었습니다. 기일이나 발행사 이름만 같으면 동일 사건으로 확정하지 않습니다. 기존 철회 묶음과 발행·배정 조건은 별도로 보존했습니다. 발행사의 등기 완료 보고는 직접 열람한 등기 기록과 구분합니다. 예를 들어 코스맥스 본문의 완료일 표기는 주석에서 접수일로 정의합니다. 주식발행내역에서 회사분할·인적분할 관련 11행을 추렸으며, 액면분할은 H04 합병·회사분할에서 제외합니다. 상장 기록의 수량과 합병·분할 보고서의 배정 비율을 확인하더라도 개별 계좌의 실제 배정 수량과 혼용하지 않습니다. [코스맥스 종료보고서](https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20260820000434)

- **H05**는 전체 후보의 실제 지급·소각·적용·정지/해제 본문, 공시 정정, 거래소 약칭으로도 확인되지 않은 발행사·대상 주권을 사건별로 확정해야 합니다. 배당 지급은 결제기관 지급 내역 또는 발행사가 실제 지급을 보고한 정기보고서가 필요합니다.
- **H04**는 동일 사건의 당사회사별 공시와 정정, 실제 등기·상장·배정 증거를 연결해야 합니다. 한화모멘텀은 실제 설립등기일을 확인할 수 있는 등기 기록 또는 이를 명시한 공시가 필요합니다.
- **H06**은 위 두 작업의 전 기간 사건 확정 이후 진행합니다. 현재 보고서는 연구용 검토 결과입니다. 과거 공개 시점이나 학습·거래 입력으로 승격된 항목은 0건입니다.
