# 5-08 공시 원문의 날짜 역할·금액/수량·정정 사실 추출

기준일: 2026-11-03. [과거 공시 204건·원문 수집](dart-historical-disclosures.md)에 이어 원문 2건의 선언 사실을 추출하고 대조했습니다. 이번 결과는 `DECLARED_PLAN`이며 실제 취득 완료·상장폐지 완료·권리/잔고 변경 이벤트가 아닙니다. 고정 체크리스트는 **7/18·39% 유지**, 5-08 진행 중입니다.

후속: [배당·소각 HTML 양식과 취득결과 보고](distribution-completion-evidence.md)를 추가했습니다. 새 원문 3건에서 배당/소각 계획과 취득결과 110행을 추출·연결하고 소각 완료와 구분합니다. 기존 XML 결과는 유지하며 아래 291건은 당시 결과, 최신 전체 검증은 322건입니다.

## 원본과 결합한 오프라인 경로

[corporate_facts.py](../AI/ai-server/app/replay/corporate_facts.py)의 extract/audit/as-of는 네트워크와 인증정보 없이 실행합니다. 먼저 공시 목록과 ZIP을 감사하고 계획·목록 해시·법인·종목·접수번호·대상 증권 표시를 대조합니다. 원문의 회사 고유번호와 제목도 목록과 같아야 합니다.

- ZIP 안의 XML이 정확히 1개일 때만 해석합니다. 원본 ZIP/개별 XML/일봉/목록 해시와 필드의 코드·원문 표시값을 결과에 남깁니다.
- 검토한 문서 유형/서식 버전만 지원합니다. 해당 본문 표 그룹 안의 코드 필드가 1개여야 하며 중복·누락·표시값 상충은 거절합니다. 정정 표의 이전 값이나 다른 재무 표의 같은 코드가 최종 본문 값을 대신하지 않습니다.
- 출력은 새 파일에만 생성하고 덮어쓰지 않습니다. audit는 원본에서 재계산한 정확한 바이트와 비교합니다. 원본·공시 목록·기존 보고서는 수정하지 않습니다.
- 숫자는 정수 문자열로 보존합니다. 천 단위 구분을 검사하고 소수/음수/지수 표기·잘못된 쉼표·18자리 초과를 거절합니다. `-`는 null이며 0으로 바꾸지 않습니다.
- 날짜는 AUNITVALUE의 날짜와 화면 표시 날짜가 일치해야 합니다. 결정일과 예정일의 시간 순서를 검사하고, 시각이나 실제 완료일을 생성하지 않습니다.

현재 지원하는 두 양식은 다음과 같습니다. 원문의 XML 코드로 범위를 고정한 해석이며 모든 기업행사 양식의 지원을 뜻하지 않습니다.

| 문서/서식 | 추출 범위 |
|---|---|
| 11332 / 1.5, 자기주식 취득 결정 | 보통주·기타주식의 예정 수량/금액·일일 주문한도, 결정일·취득 예정 시작/종료일, 본문 취득방법 |
| 11314 / 1.3, 해외 주권등 상장폐지 결정 | 보통주·기타주식의 공시된 수량, 거래소, 결정일·신청 예정일·상장폐지 예정일 |

자기주식 취득의 [공식 주요정보 가이드](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS005&apiId=2020038)도 예정 수량/금액·예상 기간과 취득결정일을 구분합니다. 이번 구현은 별도 주요정보 API를 추가 호출한 것이 아니라 [공식 원본 파일](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS001&apiId=2019003)의 코드 필드를 검사한 것입니다.

## 원문 표현과 안전한 XML 해석

실제 자기주식 공시는 설명 문장에 이스케이프되지 않은 `&` 1개가 있어 엄격한 XML 파서가 바로 읽을 수 없었습니다. 원본은 그대로 보존하고 XML의 기존 이스케이프/숫자 참조를 제외한 `&`만 문법적으로 이스케이프한 파생 문자열을 해석합니다. 이 변환 횟수와 파생 XML 해시를 기록하며 금액·날짜를 수정하는 보정은 하지 않습니다.

DOCTYPE/ENTITY 선언은 거절하고 외부 스키마를 읽지 않습니다. XML은 8 MiB·노드 50,000개로 제한하고, 기존 ZIP의 CRC/파일 경로·크기 검사도 먼저 수행합니다. 서식이나 값이 모호하면 원문 검토 대상으로 남기고 값을 채워 넣지 않습니다.

## 예정·대상 주식·정정 계보

날짜에는 DECISION_DATE, PLANNED_START/END, PLANNED_APPLICATION, PLANNED_DELISTING 역할을 붙입니다. 결과의 단일 `effectiveDate`는 null입니다. 시간이 지났다고 예정 사실을 완료 상태로 승격하지 않습니다.

보통주와 기타주식, 주수와 원화 금액을 분리합니다. 기타주식의 종목코드를 보통주에서 추측하지 않습니다. 해외 공시의 수량은 `ISSUER_REPORTED_SHARES` 단위 그대로 유지하며 설명에 나온 원주/DR 비율을 주식분할 비율로 사용하거나 국내 보통주를 상장폐지 처리하지 않습니다.

정정 본문에서는 원문에 적힌 최초제출일과 정정 전후 값을 읽습니다. 일일 주문한도의 기타주식 정정 후 값은 최종 본문의 같은 필드와 같아야 합니다. 그 외 정정 설명 행은 미해석 수를 남기고 전체 정정 검토 완료로 표시하지 않습니다.

최초제출일·동일 제목의 목록 행은 부모 **후보**입니다. 접수일은 DATE 정밀도이므로 접수번호 정렬만으로 당일의 직전 부모를 결정하지 않습니다. 후보가 여러 개면 AMBIGUOUS, 1개여도 CANDIDATE_ONLY이며 직접 부모는 null입니다. 이번 실제 정정 공시는 후보 2개·미해석 설명 행 1개를 남겼습니다.

## 시점 조회

`knownAt`은 목록 행 관측 시각과 원문 확보 시각 중 늦은 시각입니다. 발표일·결정일·예정 시작일로 소급하지 않습니다. as-of는 원본 감사 후 해당 시각에 알려진 사실만 반환하며, 메모리 조회도 사실 식별자/단계/자동 반영 금지 값을 검사합니다.

결과는 `automaticEffectAllowed=false`, `referenceEventsEmitted=0`, `priceAdjustmentApplied=false`, `usableForTraining=false`입니다. 이는 원문 사실을 추출·보관하는 단계이며 완성된 학습 특징·잔고/주가 조정·매매 판단 연결은 후속입니다.

## 실행

```powershell
# AI/ai-server. 원문은 기존 dart_documents capture로 별도 확보한 폴더입니다.
.\.venv\Scripts\python.exe -m app.replay.corporate_facts extract --index research-artifacts/dart-job --capture research-artifacts/dart-original --output research-artifacts/facts.json
.\.venv\Scripts\python.exe -m app.replay.corporate_facts audit --index research-artifacts/dart-job --capture research-artifacts/dart-original --facts research-artifacts/facts.json
.\.venv\Scripts\python.exe -m app.replay.corporate_facts as-of --index research-artifacts/dart-job --capture research-artifacts/dart-original --facts research-artifacts/facts.json --at 2024-11-18T15:30:00+09:00
```

정상 추출/감사/조회는 종료값 0, 입력·파일·원문/파생 무결성 오류는 고정 코드와 2입니다. CLI 시점 조회는 보이는 건수를 출력하고 Python의 `as_of`는 감사된 사실 내용을 반환합니다.
