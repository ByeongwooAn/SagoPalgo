[접수번호별 대조 기록](examples/historical-market-action-monthly.jsonl)에 KIND 원문 링크, SHA-256, 수집 시각, 대상과 적용일, 정정 전후의 확인 필드, 미확인 사유를 남겼습니다. 두 접수번호가 같은 원본·정정본을 가리키는 경우 접수별 증거를 보존하며 정정 관계는 문서번호 쌍으로 셉니다.

[상호·보통주 식별자 후속 대조](historical-market-action-identity.md)에서 본문 상호와 KIND 표시명이 다른 범위 내 247행의 당시 코드와 ISIN을 확인했습니다. 아래 판정 기준과 월별 수치는 원문 대조 당시의 기록입니다.

[코스피 적용 주권 후속 대조](historical-kospi-halt-scope.md)에서 390건을 상장 후보와 KRX 일자별 정지 이력에 연결했습니다. 본문이 우선주를 명시한 16건, 변경상장 공지가 해제일·대상 코드를 명시한 63건, KRX 종목별 조회 응답 547개와 미반환 91개의 근거를 기록했습니다.

본문에 보통주와 종목코드가 함께 표시되거나 본문 대상과 KIND 화면의 종목을 대조할 수 있으면 조치 필드를 확인합니다. 현재 KIND 화면과 당시 본문에 서로 다른 회사명이 표시되고 종목을 연결할 근거가 부족하면 본문에 명시된 보통주와 조치일을 기록하고 코드 확정을 보류합니다. 코스피 공지가 대상을 ‘주권’으로만 표시하면 날짜·시각과 보통주 적용 여부를 구분합니다. 정지기간 변경 공지에서는 변경 전후 문구를 보존하고 별도 적용일시의 확인 여부를 기록합니다.

공지의 적용일·시각은 거래소가 본문에 기재한 값입니다. 실제 거래정지·재개 시각과 당시 최초 공개 시각은 별도 근거가 필요합니다. 학습·거래 입력으로 사용할 때는 5-08의 시점 및 범위 검증 조건을 적용합니다. [5-08 완료 조건](multi-company-reference-cases.md)

## 재검증

AI 서버 디렉터리에서 실행합니다. 예시는 2024년 1월입니다. 원문과 영수증이 로컬에 있으면 오프라인 감사로 바로 확인할 수 있습니다. 수집 명령은 같은 요청의 해시가 일치하는 응답을 재사용합니다.

~~~powershell
$h05Artifacts = 'research-artifacts'
$h05Job = Join-Path $h05Artifacts 'h05-monthly-2024-01'
$h05Baseline = '../../docs/examples/historical-market-action-expansion.json'
$h05Manifest = Join-Path $h05Job 'review-manifest.json'

.\.venv\Scripts\python.exe -m app.replay.historical_market_action_collect 2024-01 --baseline $h05Baseline --artifacts $h05Artifacts --job $h05Job
.\.venv\Scripts\python.exe -m app.replay.historical_market_action_monthly build --manifest $h05Manifest --artifacts $h05Artifacts --job $h05Job
.\.venv\Scripts\python.exe -m app.replay.historical_market_action_monthly audit --manifest $h05Manifest --artifacts $h05Artifacts --job $h05Job
~~~

수집을 재개해 매니페스트가 바뀐 경우 새 `--report` 경로에 결과를 생성합니다. 감사 명령은 고정 후보 목록, 기존 표본, 수집 영수증과 본문 해시를 검사하고 보고서를 다시 계산해 바이트 단위로 대조합니다.

35개월 보고서를 오프라인으로 재계산해 접수번호의 누락·중복 0건과 접수별 대조 기록의 일치를 확인했습니다. 접수별 기록의 SHA-256은 `ea60614da213fd71b782f4367f0001f347632d8da6aa7828d4cd1b3d1e3d5e82`입니다. AI 서버 전체 회귀는 1,414건 통과, 격리 Java/MySQL 내보내기 자료가 필요한 조건부 검사 1건 건너뜀입니다.
