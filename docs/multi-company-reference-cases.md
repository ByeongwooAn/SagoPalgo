## 5-08의 고정 목표 범위

이 문서부터 1차 완성 범위를 **2023-11-01~2026-11-02, KRX KOSPI·KOSDAQ 보통주**로 명시합니다. 당시 상장 종목을 포함하며 현재 생존 종목만으로 과거를 구성하지 않습니다. KONEX·NXT·우선주·ETF/ETN·신주인수권·해외/소수점 상품은 이 기준정보 범위 밖이며 이후 별도 계약으로 확장합니다. 기존 5번 고정 체크리스트의 분모 18개는 변경하지 않습니다.

## 구현과 해석

- `app/replay/kind_cases.py`의 `capture/build/audit/as-of`는 기존 연구 CLI와 동일하게 로컬 실행합니다. `build/audit/as-of`는 네트워크를 사용하지 않습니다. FastAPI·실시간 수집·주문 코드는 변경하지 않습니다.
- 검토한 KOSDAQ 양식 70760/70769/70764/70797/70799만 지원합니다. 제목·발행회사·보통주·종목코드·날짜 필드의 유일성을 검사합니다. 중복 필드·다른 주식 종류·정정 양식·장중 정지 시각·비정수 분할 비율·다른 HTML 구조는 임의 변환하지 않고 실패합니다.
- 정지/해제 본문에는 코드가 없어 설정의 회사명을 검사하고, **같은 범위의 코드가 명시된 원문**으로 회사/코드 대응을 추가 대조합니다. `REVIEWED_ISSUER_MAPPING`으로 표시하며 본문에 코드가 있는 척하지 않습니다.
- 본문·수신 시각·SHA-256을 로컬 캐시에 보존합니다. URL별 GET은 1회만 예약하고 실패/미완료 예약은 자동 재시도하지 않습니다. 새 호출 수가 명시한 예산을 넘으면 통신 전에 중단합니다. 변조/실패 예약도 신규 호출 전에 검사합니다.
- `referencePack`은 기존 `SAGOPALGO_MARKET_REFERENCE_V1` 모델에 직접 검증합니다. 상장 편입/제외 2건과 기업행사 참조 3건이며, 빈 `coverage`는 전체 시장 확보 선언을 의미하지 않습니다.
- 분할 참조의 날짜는 **변경상장일**입니다. 다른 법적 효력일·배당기산일·발행일과 합치지 않으며 원주가나 잔고를 자동 보정하지 않습니다. 해제는 기존 모델의 OTHER와 `RESUMPTION_DATE` 근거로 보존합니다.
- `as-of`는 수집 시각과 사건 날짜를 각각 적용합니다. 최초 상장 전/폐지 전 상태를 근거 없이 생성하지 않습니다. `lastAnnouncedRestriction`은 날짜 기준 마지막 확인 공시이며 주문 가능 상태를 확정하지 않습니다. 거래정지 때 종목이 상장폐지된 것으로 처리하지 않습니다.
- 원문의 과거 URL 날짜를 초 단위 공개 시각으로 바꾸지 않습니다. `FETCH_TIME_ONLY`이므로 2024년 시점 조회에서는 이번에 수집한 원문 사건이 보이지 않습니다. 과거 시점 가용성 확보는 완료 조건 5에 남습니다.

## 재실행

`AI/ai-server`에서 실행합니다. 처음 자료를 확보할 때만 `capture --max-new-requests 5`를 사용합니다. 이미 확보된 캐시는 아래처럼 새 호출 예산 0으로 감사·재사용할 수 있습니다.

```powershell
.\.venv\Scripts\python.exe -m app.replay.kind_cases capture --scope ../../docs/examples/kind-reference-cases.json --cache research-artifacts/kind-case-cache --max-new-requests 0
.\.venv\Scripts\python.exe -m app.replay.kind_cases build --scope ../../docs/examples/kind-reference-cases.json --cache research-artifacts/kind-case-cache --report research-artifacts/kind-cases-20261103/report.json
.\.venv\Scripts\python.exe -m app.replay.kind_cases audit --scope ../../docs/examples/kind-reference-cases.json --cache research-artifacts/kind-case-cache --report research-artifacts/kind-cases-20261103/report.json
```

보고서는 사실·해시·기준정보 묶음을 포함합니다. `as-of`에 동일 인자와 `--stock 086520 --at <보고서의 마지막 수집 시각> --date 2024-04-24`를 지정하면 날짜 기준 마지막 정지 공시를 조회할 수 있습니다. `--at 2024-04-25T08:00:00Z`로 조회하면 현재 수집 원문은 제외됩니다. 기존 보고서가 있으면 재계산 결과와 일치하는지 검사하고 덮어쓰지 않습니다. 설정을 바꿔 사례 범위를 확대할 때는 새 보고서 경로를 사용합니다.

실제 원문·보고서는 Git에서 제외되는 `AI/ai-server/research-artifacts/` 아래에 보관했습니다. Git에는 코드·가상 테스트·공개 출처 설정·문서만 포함합니다.

## 검증 결과와 다음 순서

- 전체 AI 서버 **355건 통과, 실패/오류/건너뛰기 0건**(기존 322 + 신규 33). 기존 Starlette/AnyIO 폐기 예정 별칭 경고 1건은 유지됩니다. Java 저장 내보내기 fixture를 포함했습니다.
- 실제 5건을 통신 금지 상태로 재감사하고 신규상장/폐지 전후·정지 전/중/해제일·수집 직전/직후를 확인했습니다. 재검증 추가 GET 0회, 기존 가격 작업 파일 29개의 해시 불변을 확인했습니다.
- 결과: 대표 사례 5/5, 기업 3곳, 상장 참조 2건·행사 참조 3건. 기존 가격/공시 수집 범위는 유지하며 5번은 **7/18·39%, 5-08 진행 중**입니다.

다음은 **합병·이전상장 실제 사례와 과거 종목군의 기초 목록 확보**를 우선합니다. 이후 전체 기간 달력/세션을 보강하고 새 사례의 실제 가격을 대조합니다. 삼성전자 전용 양식 확장만 반복하지 않고 위 7개 조건의 누락 수를 줄입니다. 데이터 공급원에서 전체 범위나 과거 시각을 제공하지 않으면 미확보 항목을 명시하며 완료 범위를 임의 축소하지 않습니다.
