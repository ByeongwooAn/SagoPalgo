# U05 공개 체결 피드와 호가 모형의 제한 대조

기준일: 2026-11-06. **공개 체결 기반의 사후 가격·수량 진단 도구와 실제 표본 대조를 구현했습니다.** 동일 공급자의 별도 체결/호가 피드를 비교한 것이며, 독립 거래소 원장이나 본인 계좌 체결과 대조한 결과는 아닙니다. U05의 공개 자료 범위는 완료했지만 **계좌 체결·정확한 수량·실제 비용 검증은 근거 대기**입니다. ②-08과 5-09 전체를 완료로 올리지 않습니다.

## 표본과 비교 기준 고정

기존 [호가 모형 검사](quote-execution-quality.md)의 실제 표본 4개와 가상 주문 28개를 그대로 사용했습니다. KOSPI 005930, KOSDAQ 017890, 247540의 재시작 전/후 두 구간입니다. 시장가 매수/매도·시장성 지정가 매수/매도·비시장성 지정가 매수/매도·잔량 초과 매수 7개씩이며, 기존 표본은 최초의 추정 가능한 호가를 고른 검사이므로 무작위·시장 대표 표본이 아닙니다.

이번 공개 체결 결과를 보고 주문·표본을 새로 고르지 않았습니다. 입력/주문 해시·비교 정책·통제 사례를 먼저 로컬 표본 계획에 기록했습니다. 각 주문의 시도 시각을 기준으로 **이전 1초~이후 2초**의 고정 문맥을 사용합니다. 모든 가격의 체결을 선택한 뒤 추정 가격과 비교하며, 가장 유리한 가격·가장 가까운 체결·일치하는 체결만 골라 기준을 만들지 않습니다. 이 3초 문맥은 IOC 주문의 유효기간이 아닙니다.

추가 수집·계좌 조회·실주문은 없었습니다. 실제 원문과 가격·수량·진단 상세·표본 계획은 Git 제외 `AI/ai-server/research-artifacts/execution-comparison-20261106/`에 보관합니다. [공개 요약](../examples/public-tape-comparison-validation.json)에는 건수·상태·해시만 기록합니다.

## 입력·시각·계보와 차단

새 `app.replay.execution_comparison`은 기존 `estimate_quotes`를 변경하지 않고 호출한 뒤, 같은 원본의 **TRADE 이벤트**로 사후 진단을 생성합니다. 모형의 QUOTE 잔량으로 공개 체결을 합성하지 않습니다. 동일 KIS 공급자의 별도 피드라는 관계를 명시하고 `independentProviderConfirmed=false`로 고정합니다.

- 원문 해시·이벤트 ID·저장/변환 무결성은 기존 틱 감사로 검사합니다. 출처/정책/주문/호가 단위 팩/추정 보고서 해시를 연결합니다.
- 체결 영업일은 공급자 날짜가 있어야 합니다. 세션 코드의 장중 의미, 양의 수량, 시계 역전 여부를 검사하고 미확인/역전/0수량 자료는 제외 사유와 원문 해시를 보존합니다. 장중 코드만으로 연속매매·VI/CB 없음까지 확정하지 않습니다.
- `marketTimeResolutionMs=1000`은 초 단위 공급자 라벨의 불확실성을 다루는 **비교 정책**입니다. 라벨을 정확한 체결 순간으로 사용하지 않고 `[라벨, 라벨+1초)` 구간으로 취급합니다. 마이크로초가 있는 라벨은 이 정책에서 임의로 내림하지 않고 제외합니다.
- 문맥 경계에 걸친 체결 구간은 별도로 기록하며, 완전히 포함된 구간만 가격·수량 진단에 사용합니다. IOC 유효기간 안에 완전히 포함된 구간과 경계에 걸친 구간도 따로 기록합니다. 같은 초의 해시 정렬을 거래소 순번으로 사용하지 않습니다.
- 문맥이 내보내기 범위를 벗어나거나 명시된 수집 공백을 가로지르면 비교 불가로 처리합니다. 문맥을 몰래 줄이거나 공백을 메우지 않습니다. 수신 공백·누적 수량 이상은 원래 감사 사유로 보존합니다.
- 내보내기 시각 이전의 사후 조회, 사후 조회 시각보다 미래인 규정 조회 override, 합성 자료 미승인 사용을 거절합니다. 공식 격자/장중 제한을 지정하면 기존 모형의 차단이 그대로 적용됩니다.
- 기존 기본 가용 시각 차단·명시적 수신 시각 가정·잔량 재사용 금지·수수료 가정을 유지합니다. 이후 공개 체결을 과거 주문 판단이나 호가 선택에 되먹이지 않습니다.

가격 진단은 관측 범위·거래량 가중 평균과 추정 평균의 차이, 추정 가격별 관측 수량과의 차이를 보존합니다. 이는 **문맥 진단이며 실현 슬리피지·내 주문의 체결 수량 오차가 아닙니다.** 공개 체결에는 주문 귀속·체결 상대/주도 방향·대기열 정보가 없습니다. 같은 시장 체결량을 여러 주문에 배분하지 않으며 중복 참조 건수를 별도로 표시합니다. 여러 가상 시나리오의 관측 수량을 합쳐 새로운 시장 체결량으로 계산하면 안 됩니다.

`exactQuantityComparison/actualCostComparison=NOT_ASSESSABLE`, `accountFillStatus=NOT_PROVEN`, `realizedSlippage/actualCostDifference/exactQuantityDifference=null`, 거래/전략 사용 가능 여부 false를 유지합니다. 모형의 0추정·미체결·취소를 실제 계좌의 0체결·취소 성공으로 바꾸지 않습니다.

## 실제 표본 결과와 해석

기존 공식 호가 단위 팩을 명시적 사후 근거로 연결했습니다. 규정 조회 시각은 이번 사후 조회 시각이며 미래의 날짜로 설정하지 않았습니다. 기존 공식 격자 보고서 28개의 **추정 결과가 모두 동일**했습니다. 원문·정책·주문·기존 보고서·규칙 팩을 포함한 기존 126개 파일은 바이트 해시가 유지됐습니다.

| 항목 | 결과 | 해석 |
|---|---:|---|
| 고정 주문 문맥 | 28개 모두 공개 체결 관측 | 연속·전체 시장 시세의 완전성을 뜻하지 않음 |
| 모형 결과 | 추정 전량 16·부분 IOC 4·판정 불가 8 | 비시장성 지정가 8개는 공식 호가 단위 밖의 가격이어서 차단됨. 미체결 성공으로 세지 않음 |

44개 가격 미관측은 이 짧은 관측 범위에서 같은 가격이 발견되지 않았다는 뜻입니다. 관측 누락, 반대편 거래, 호가 변경·대기열·상대 주문, 가상 주문이 실제로 시장에 제출되지 않았다는 한계가 있어 실제 미체결이나 모형 오류로 단정하지 않습니다. 일치율을 올리기 위해 비교 창을 늘리거나 모형을 이 표본에 맞춰 조정하지 않았습니다.

별도 통제 2건도 확인했습니다. 039020 무수신 표본은 `NO_ELIGIBLE_PUBLIC_TRADES`와 모형 `NOT_ASSESSABLE/NO_VISIBLE_QUOTE`입니다. 유동성 0·거래정지·체결 실패로 바꾸지 않습니다. 247540 재시작 사이에 기록된 공백의 주문/문맥은 모두 판정 불가이며 공백 이전 잔량을 실제 체결로 올리지 않습니다. 공백 경계는 사후 관측 가정이지 과거 전략이 미리 알았던 정보가 아닙니다.

## 실행

[비교 정책](../examples/public-tape-comparison-policy.json)과 [스키마](../examples/public-tape-comparison-policy.schema.json)를 사용합니다. 아래는 `AI/ai-server`에서 기존 로컬 표본을 읽는 명령이며 출력은 새 이름이어야 합니다.

```powershell
.\.venv\Scripts\python.exe -m app.replay.execution_comparison --input research-artifacts/tick-readiness-20261106/actual-export.json --config research-artifacts/quote-execution-20261106/actual-export-config.json --session-evidence research-artifacts/quote-execution-20261106/kis-session-source.py.txt --quote-policy research-artifacts/quote-execution-20261106/00-market-buy-policy.json --orders research-artifacts/quote-execution-20261106/00-market-buy-orders.json --comparison-policy ../../docs/examples/public-tape-comparison-policy.json --tick-rules ../../docs/examples/historical-tick-rules.json --rules-known-at 2026-11-06T12:35:16Z --as-of 2026-11-06T12:35:16Z --output research-artifacts/public-tape-comparison-new.json
```

`--intraday-timeline --timeline-sha256 --market --order-class`는 함께 지정합니다. 규칙 팩 없이 `--rules-known-at`만 지정하면 기존 모형과 동일하게 거절합니다. 공식 팩을 생략하면 기존 모형의 가정 격자가 유지되며, 실제 비용 팩이 자동 적용되는 기능은 아닙니다.

입력 주문은 최대 1,000개이며 중복·범위·정밀도를 검증합니다. 결과 파일은 배타 생성하고 오류는 원문 값을 숨긴 고정 코드로 출력합니다. 종료 코드 0은 **사후 진단 보고서 생성 성공**이며, 가격 미관측·수량 판정 불가도 정상적인 진단 결과입니다. 입력/파일 오류는 2입니다. 숫자를 억지로 일치시키거나 비교 불가를 성공 체결로 바꾸지 않습니다.
