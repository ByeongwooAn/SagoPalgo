# U03 과거 호가 단위·체결 엔진 연결 완료

2026-11-06. [초기 스냅샷](official-tick-rules.md)의 남은 작업을 완료했습니다. 대상은 **KRX KOSPI/KOSDAQ 보통주**, 기간은 2023-11-01~2026-11-06(끝 제외 11-07)입니다. 기존 고정 과거 목표 2023-11-01~2026-11-02를 포함합니다. 다른 상품·시장으로 확대하지 않습니다.

## 공식 본문과 기간

기존 공식 업무규정 본문에서 시행세칙 직접 연결 ID를 찾았습니다. [KRX 새 규정 포털](https://rule.krx.co.kr/out/index.do)의 본문 POST는 bookid·noformyn=N·oldyn=Y로 과거 판본을 지정합니다. 구 사이트의 접근 실패를 과거 규정 부재로 판단하지 않았습니다.

- KOSPI 제153~177차 **25개**, KOSDAQ 제109~119차 **11개**, 총 **36개** 본문을 확보했습니다. 기준일 이전인 2023-09-01 판본과 현재 연혁의 최신 판본까지 포함합니다.
- 반환 BOOKID·원문 해시·연속 개정 차수·KOSPI 제32조/KOSDAQ 제18조의 가격대 7개를 검사했습니다.
- **모든 판본에서 보통주 가격대/단위가 동일**합니다. 따라서 고정 기간의 보통주 격자를 한 구간으로 연결했습니다. 하나라도 다른 표가 나오면 자동 병합을 거부합니다.
- 연혁의 개정일을 시행일로 치환하지 않습니다. 2025년 2월 개정/3월 시행 등 날짜 차이는 기존 부칙 근거와 구분하며, 이 작업은 모든 중간 판본에서 보통주 격자가 같다는 점으로 연속성을 확인합니다. 법령 전체가 동일하다는 뜻이 아닙니다.
- KOSPI의 ETF/ETN 단위 변경 조항은 보통주와 분리했습니다. ETF/ETN/ELW·소수점·NXT·해외·시간외 특수 체결 가격에는 적용하지 않습니다.

[판본 원장](../examples/historical-tick-evidence.json)은 36개 bookid·차수·목록 날짜·수집 시각·원문 SHA-256을 연결합니다. [과거 규칙 팩](../examples/historical-tick-rules.json)의 evidenceSha256은 시장별 원장의 canonical JSON 해시입니다. 원문과 영수증은 Git 제외 경로 `AI/ai-server/research-artifacts/official-ticks-history-20261106`에 보존합니다.

`app.replay.tick_rules.build_history(folder)`는 네트워크 없이 원문/영수증 해시·반환 ID·개정 차수·본문 표를 재검증하고 팩/원장을 생성합니다. 자동 감사를 통과한 출처와 수동으로 작성한 외부 팩을 같은 공식성 인증으로 취급하지 않습니다.

## 엔진·CLI 계약

`quote-scenario`에 선택적 `--tick-rules <팩>`과 `--rules-known-at <조회 시각>`을 추가했습니다. 팩이 없으면 기존 계산과 보고서를 그대로 유지합니다. 팩이 있으면 지정가와 소비하는 각 호가를 **각 가격 자신의 구간 단위**로 검사합니다. 가격 반올림·단일 정책 상수 수정·실주문 전송은 없습니다.

이 경로는 데이터가 KRX 보통주라는 범위 선언을 전제로 합니다. 자동 상품 식별 기능이 아닙니다. 기간 밖·지원하지 않는 시장은 차단하며, 한국 날짜는 대상 기간의 UTC+9를 사용합니다. Windows tzdata 설치에 의존하지 않습니다.

기본 근거 조회 시각은 주문 판단 시각입니다. 규정 수집 시각이 이후이면 `TICK_RULE_NOT_YET_KNOWN`으로 차단합니다. 나중에 확보한 규정으로 사후 대조하려면 `--rules-known-at`을 명시해야 합니다. 보고서에 `exPostEvidence=true`·팩 해시·조회 시각을 기록하며 거래/전략 검증 가능 상태로 승격하지 않습니다. 조회 시각만 지정하고 팩이 없으면 거절합니다.

## 실제 자료 대조와 검증

기존 실제 호가 보고서 **28개는 기본 실행에서 바이트 일치**했습니다. 같은 28개를 공식 팩의 명시적 사후 대조로 재실행해 [판정 요약](../examples/historical-tick-validation.json)을 남겼습니다. 원본 보고서와 새 연구 보고서는 별도 경로에 보존했습니다. 공개 호가 모형의 비교이며 증권사 계좌 체결·실제 비용 검증을 뜻하지 않습니다.

신규 회귀는 엔진의 미래 근거 차단·명시적 사후 대조·팩 없는 override 거절·합성 연혁의 원문 변조를 검사합니다. 초기 가격/날짜 경계 34건을 포함한 관련 69건이 통과했습니다. 전체 회귀 **1,233건 통과·실패/오류/제외 0건**, 기존 의존성 경고 1건입니다. 고정 목표의 시장/날짜 2196개 조회도 확인했습니다.
