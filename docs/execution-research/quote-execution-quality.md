- [x] ②-06 지연·비용/세금·호가 단위 가정과 기존 장중 제한 타임라인 연결

- [ ] ②-08 독립적인 실제 비용·호가 단위·계좌 주문 체결과 대조

`quote_execution.py`는 실제 주문을 보내지 않는 연구용 IOC 추정입니다. 입력 [주문 스키마](../examples/quote-order.schema.json)·[정책 스키마](../examples/quote-execution-policy.schema.json)를 검증하고 Decimal 정밀도 96으로 계산합니다.

- 매수는 ask, 매도는 bid를 순회합니다. 지정가를 넘는 호가는 사용하지 않습니다. 비시장성 지정가는 대기열 체결을 추측하지 않고 미체결·취소로 남깁니다.
- 각 잔량의 참여율, 현금/보유 수량, 주문 금액을 제한합니다. 수수료·매도세는 주문 누적 금액 기준 올림 가정이며 실계좌 요율이 아닙니다. 체결이 없으면 비용·자원이 변하지 않습니다.
- 같은 가격의 잔량이 후속 스냅샷에 다시 나타나도 새 주문 식별자가 없으므로 보충됐다고 추정하지 않습니다. 전체 표본의 매수/매도 방향·Decimal 가격별로 누적 소비합니다. 보수적 가정이며 실제 잔량 복구를 재현한 결과가 아닙니다.
- 기본은 `EXPORT_KNOWN_AT`입니다. 당시 DB 커밋/전략 가용 증거가 없으므로 이번 실제 표본의 과거 주문은 **차단**됩니다.
- 별도 연구 모드는 `RECEIPT_DERIVED_SCENARIO`, 추정 날짜 앵커 허용·연속매매 미확정 허용을 명시해야 합니다. 같은 시장 초의 호가 순서도 기본은 보류이며, `CLIENT_RECEIPT_SCENARIO`를 별도 선택한 경우에만 클라이언트 수신 순서 가정을 적용합니다. 동일 수신 시각까지 겹치면 계속 보류합니다. 거래소 순번을 생성하지 않습니다.
- 입력한 수집 공백 안의 판단/체결 및 공백 이전 호가 사용을 차단합니다. 선택적으로 기존 불변 장중 타임라인을 연결하면 판단·체결 시각에 알려진 중단/단일가/해당 방향 프로그램 정지가 가정보다 우선합니다. 시장/해시 불일치·합성 자료의 미승인 사용은 실패합니다.
- 보고서의 `accountFillStatus=NOT_PROVEN`, `usableForTrading=false`, `usableForStrategyValidation=false`는 항상 유지됩니다. 기존 분봉 replay와 R5_FOUNDATION_2/3 형식은 변경하지 않습니다.

실제 호가 4개 표본에서 시장가 매수·매도, 시장성 지정가 매수·매도, 비시장성 지정가 매수·매도, 잔량 초과 부분 체결의 **7개씩 총 28개**를 대조했습니다. 원문 호가의 가격/잔량으로 별도 계산한 기대값과 모두 일치합니다. 비용/세금 0·호가 단위 1·연속매매/수신 순서/가용 시각은 이 프로브의 **명시적 가정**입니다. 같은 공급자 호가의 가정 대조이며 독립 거래소 체결·KB 비용·내 주문 체결 증명이 아닙니다. 기본 가용 시각 모드에서 4개 표본 모두 보류됨을 함께 확인했습니다.
