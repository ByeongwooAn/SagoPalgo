# 삼성전자·SK하이닉스 로컬 모델 독립 평가

2026-11-18에 두 종목의 가격·거래량 L2 로지스틱 회귀 모델 `daily-l2-logistic-v1`을 학습했습니다. 공통 최종 평가 **142일**에서 삼성전자는 검증에서 정한 매수 관찰 임곗값에 도달한 날이 없었고, SK하이닉스는 70회 진입해 기본 비용 차감 후 **−47.91%**를 기록했습니다. 두 종목 모두 학습 상승 빈도 기준보다 로그 손실이 높아 모의 전략 채택을 보류합니다. 3단계 앱 추론 일치 검증에는 이 버전의 모델을 사용합니다. ## 평가 전 고정한 입력과 설정

- 종목별 KIS 원주가 일봉 730건과 1단계 날짜 목록의 SHA-256을 재검사했습니다. 공통 학습 424일, 검증 141일, 최종 평가 142일의 신호일·정답일 쌍이 각 종목 전체 표본과 동일합니다. 신호일은 **2026-04-02~10-30**, 정답일은 **2026-04-03~11-02**입니다. T−20부터 T까지의 확정 OHLCV로 특징 7개를 계산하고, 바로 다음 개장일의 종가가 시가보다 높을 때 상승으로 분류했습니다. [특징 계산식과 고정 날짜](samsung-daily-training-input.md#특징과-정답-규격) · [두 종목 공통 날짜 및 입력 해시](hynix-daily-training-input.md#공통-날짜-확정)
- 검증은 47일씩 3개 연속 구간으로 나눠 학습 창을 확장했습니다. 각 구간의 첫 신호일보다 정답일이 앞선 424·470·517건으로 해당 구간의 표준화와 모델을 각각 적합했습니다. 마지막 학습 정답일은 순서대로 2025-08-28, 2025-11-10, 2026-01-19이며 이후 구간은 각각 다음 개장일에 시작합니다.
- 검증 예측 확률에서 50%부터 75%까지 2.5%p 간격의 임곗값과 거래 없음 후보를 비교했습니다. 기본 비용 차감 누적 수익률이 가장 큰 값을 선택하고 동률이면 거래가 적은 쪽, 다시 동률이면 진입 안 함 또는 더 높은 임곗값을 선택했습니다. 진입 조건은 상승 확률이 임곗값 이상입니다.
- 최종 모델과 표준화는 원래 학습 구간 424건에만 적합했습니다. `StandardScaler` 및 `LogisticRegression(penalty="l2", C=1.0, solver="lbfgs", max_iter=1000, tol=1e-9)`을 CPU 한 스레드에서 사용했습니다. 두 모델과 종목별 임곗값을 고정한 뒤 최종 평가 행의 특징·정답을 구성했습니다.

모든 전략은 같은 초기 자산 1로 시작합니다. 진입일에 당일 시가를 기준으로 전액 진입하고 종가를 기준으로 전량 청산하는 비례 체결 모형으로, 다음 진입에 남은 자산을 사용합니다. 거래 없는 날의 수익률은 0입니다. 최대 낙폭은 초기 자산을 포함해 일별 청산 후 자산의 최고점 대비 하락률 최댓값이며 거래 횟수는 한 번의 진입·청산을 1회로 셉니다.

기본 비용은 편도 수수료 5bps, 편도 체결 불리분 5bps, 매도 제세금 20bps입니다. 높은 비용은 각각 10bps, 15bps, 20bps입니다. 두 종목과 검증·최종 구간 전체에 같은 고정 시나리오를 사용했습니다. 매수가는 `시가 × (1 + 체결 불리분)`, 매도가는 `종가 × (1 − 체결 불리분)`으로 잡고 체결 대금에 편도 수수료와 매도 제세금을 적용했습니다. 주수 단위·최소 수수료·절사·유동성·장중 최대 낙폭은 반영 범위 밖입니다. 실제 계좌 수수료와 정산은 별도의 실사용 자료로 대조합니다. ## 재현과 앱에서 확인

`AI/ai-server`에서 1단계의 원본 일봉과 해시가 고정된 날짜 목록을 같은 로컬 폴더 구조에 둔 뒤 실행합니다. 실행 환경은 Windows, Python 3.12.4, scikit-learn 1.7.2, NumPy 2.5.5, SciPy 1.18.1, joblib 1.6.0, threadpoolctl 3.8.0입니다.

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-learning.txt numpy==2.5.5 scipy==1.18.1 joblib==1.6.0 threadpoolctl==3.8.0
.\.venv\Scripts\python.exe -m app.replay.daily_learning --artifacts research-artifacts --output research-artifacts/daily-learning-v1
(Resolve-Path research-artifacts/daily-learning-v1/app-summary.json).Path
```

앱의 **추천 → 로컬 모델 평가**에서 마지막 명령이 출력한 경로를 넣고 **결과 열기**를 누르면 두 종목의 기간·모델 버전·임곗값·예측 지표·전략별 비용 민감도를 볼 수 있습니다. 결과는 로컬 요약 파일에서 읽습니다.
