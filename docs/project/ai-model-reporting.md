# AI 모델 학습 보고서 작성 기준

모델을 학습하거나 재학습할 때마다 실행을 식별할 수 있는 Markdown 보고서를 `docs/project/`에 작성합니다. 실패하거나 최종 평가를 끝내지 못한 실행도 실행 조건, 확인한 결과, 실패 원인 또는 미평가 사유를 기록합니다. 한 실험에서 여러 종목을 학습하면 모델 버전과 평가 결과를 종목별로 식별할 수 있게 한 보고서에 정리할 수 있습니다.

기존 `docs/project/`를 공통 위치로 사용합니다. 데이터 감사, 알고리즘 설계, 독립 평가, 프로젝트 실행 순서가 서로 연결되고 앱과 학습 도구 양쪽에서 동일한 보고서를 찾을 수 있습니다. 보고서 제목에 대상과 모델을 쓰고 문서 안에 실행 날짜, 모델 버전, 실행 식별자를 기록합니다. 같은 모델을 다시 학습하면 실행별로 구분해 이전 결과를 보존합니다. 시세 원본, 학습 모델 파일, 날짜별 예측·모의 체결 원장 등 개인 로컬 산출물은 기존 Git 제외 경로에 보관하고, 보고서에는 공유 가능한 집계와 재현에 필요한 산출물 이름·해시를 기록합니다. ## 보고서 구성

| 항목 | 기록할 내용 |
|---|---|
| 실험 목적과 결론 | 무엇을 검증했는지, 이전 모델이나 단순 기준과 비교해 무엇이 개선되거나 저하됐는지, 이번 결과로 내린 채택·보류 판단과 그 근거를 씁니다. |
| 예측 목표와 데이터 | 예측 결과의 뜻과 예측 시점, 정답 확정 시점, 종목·시장·표본 수, 학습·검증·최종 평가 기간, 포함·제외·누락 기준, 입력 버전 또는 해시를 기록합니다. 여러 종목을 비교하면 공통 평가 표본을 명시합니다. |
| 알고리즘 설계와 선택 이유 | 특징마다 어떤 정보를 담는지, 전처리, 목표함수, 모델 구조, 주요 설정값, 종목별 학습 여부를 설명합니다. 표본 크기와 사용 목적을 근거로 왜 골랐는지 쓰고, 실제 탐색한 설정과 실험 전에 고정한 설정을 밝힙니다. 기존 설계를 이어 쓰면 설계 문서에 연결하고 이번에 바꾼 점을 설명합니다. |
| 검증과 비교 기준 | 시간순 분할·정답 경계, 표준화와 모델 적합 범위, 임곗값을 고른 구간과 기준, 독립 평가에서 고정한 항목을 명시합니다. 기준 모델·전략의 계산식과 같은 표본·체결·비용 조건을 기록합니다. |
| 예측과 모의매매 결과 | 방향 적중률·확률 품질 등 예측 지표를 비교합니다. 매매까지 평가했다면 진입 기준, 체결가, 투입금, 비용 가정, 거래 건수, 순수익률, 최대 낙폭, 비용 민감도를 기록합니다. 실패·미실행·자료 부족은 사유와 함께 표시합니다. |
| 재현과 적용 범위 | 실행 환경·명령, 코드와 입력 버전, 인자와 필요한 난수 설정, 결과 파일 이름·해시, 실제 수행한 검사와 결과를 남깁니다. 해석이 가능한 기간과 표본, 적용에 영향을 미치는 미검증 조건을 적습니다. |

## 수치·표·그래프 설명 원칙

- **수치**는 무엇을 세거나 나눈 값인지, 단위와 분모·기간, 비교 대상, 값이 커지거나 작아질 때의 의미를 설명합니다. 예를 들어 적중률 50.00%는 평가 142일 중 71일을 맞혔다는 뜻이고, 45.77% 기준과의 차이는 4.23%p입니다. 거래가 0회인 모델의 0% 수익률은 현금만 보유한 결과로 해석합니다.
- **표**에는 지표와 단위, 기간, 모델과 기준 이름을 표시합니다. 표 바로 아래에서 독자가 먼저 봐야 할 비교를 구체적인 건수와 차이로 설명합니다. 확률을 방향으로 바꾸는 분류 기준과 모의매매를 결정하는 진입 임곗값이 다르면 둘 다 표시합니다. 적중률·로그 손실·수익률이 다른 방향으로 움직일 때는 실제 정답 수, 진입일 수익·손실 폭, 비용 등 확인 가능한 자료로 설명합니다.
- **그래프**를 넣을 때는 제목, 축의 값과 단위, 관측 기간, 범례, 표본 수와 비교 기준을 표시합니다. 그래프 바로 아래에 기준점, 눈에 띄는 구간이나 전환점, 차이의 크기와 해석 한계를 씁니다. 누적 자산 그래프에는 초기 자산과 비용 조건을 표시하고, 최대 낙폭을 설명할 때는 해당 고점과 이후 저점을 짚습니다. 확률 보정 그래프에는 구간별 표본 수와 예측 확률에 대응하는 관측 빈도를 같이 제시합니다.
- **검증 범위**가 바뀌면 날짜·대상·비용·표본 조건의 차이를 밝힙니다. 확인한 관측과 가능한 설명을 구분하고, 소수 표본이나 단일 기간으로 설명할 수 있는 범위를 명시합니다. 계산에 쓰인 산출물과 문서 수치가 일치하는지 대조한 뒤 완료합니다.
