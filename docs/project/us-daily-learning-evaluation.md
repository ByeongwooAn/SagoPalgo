# 애플·엔비디아 일봉 모델 학습과 독립 평가

2026-11-19 개인 로컬 학습 실행 `us-daily-learning-v1`에서 애플(AAPL)과 엔비디아(NVDA)의 L2 로지스틱 회귀 모델을 만들었습니다. 두 모델 모두 공통 최종 평가 143일에서 학습 구간 상승 빈도 기준보다 로그 손실이 높았습니다. 애플의 비용 차감 수익률은 4회 진입에서 +0.37%였고, 높은 비용 가정에서는 −1.66%였습니다. 엔비디아는 검증에서 현금 유지가 선택돼 진입 0회였습니다. 두 모델의 전략 채택은 보류하고 앱 추론과 수동 모의 경로 검증에 활용합니다. ## 알고리즘과 평가 조건

개인 로컬 CPU에서 종목별 표준화와 L2 로지스틱 회귀를 적용했습니다. 21개 확정 일봉의 당일 시가→종가, 1·5·20일 수익률, 고저폭, 20일 변동성, 상대 거래량을 사용합니다. 다음 거래일의 `종가 ÷ 시가 − 1`이 양수이면 상승입니다. 기존 일봉 기준선과 같은 알고리즘은 소수의 특징과 제한 표본에서 확률과 특징별 기여를 함께 점검하기 위한 선택입니다. 규제 강도 `C=1.0`, `lbfgs`, 최대 1,000회로 고정했습니다. [기준 모델 설계](logistic-regression-baseline.md)

검증에서는 과거 구간을 늘리며 47일씩 평가하고, 각 검증 묶음의 첫 신호 전에 정답이 나온 자료로만 표준화와 모델을 적합했습니다. 기본 비용 차감 수익률에 따라 임곗값 50~75%를 2.5%p 간격으로 비교했고, 현금 유지도 후보로 넣었습니다. 애플은 검증 141일에서 60% 임곗값의 8회 진입이 +0.98%였으며, 엔비디아는 현금 유지가 선택됐습니다. 두 모델의 표준화·가중치와 임곗값을 고정한 뒤 최종 143일을 평가했습니다.

기본 비용 가정은 편도 수수료 10bp와 체결 불리분 5bp입니다. 높은 비용 가정은 편도 수수료 25bp와 체결 불리분 15bp, 매도 비용 1bp입니다. 1bp는 0.01%p입니다. USD로 당일 시가 진입과 종가 청산을 가정한 연구 시나리오이며, 실제 브로커 비용과 체결은 후속 모의·운영 검증에서 대조합니다.

## 재현과 앱 연결

학습은 Windows, Python 3.12.4, scikit-learn 1.7.2와 BLAS 한 스레드로 실행했습니다. 로컬 수집 파일로 같은 학습을 재실행해 두 모델과 날짜 산출물의 바이트 일치를 확인했습니다. 아래 명령은 `AI/ai-server` 폴더에서 실행합니다.

```powershell
.\.venv\Scripts\python.exe -m app.replay.us_daily_learning --capture research-artifacts/us-daily-capture-20261119 --output research-artifacts/us-daily-learning-v1-recheck
$env:SAGOPALGO_VERIFY_FROZEN_DAILY = '1'
.\.venv\Scripts\python.exe -m pytest -q -s tests/test_daily_inference.py
```
