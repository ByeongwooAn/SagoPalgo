초기 단일 종목 범위에서 주 6회 확보를 기준 시나리오로 두면 **첫 앱 시험은 2026년 12월 초~중순**, **전체 완료 목표는 2026년 12월 중순~2027년 1월 초**입니다. 실제 거래일 검증은 장 마감 후 신호 생성과 다음 거래일 모의 주문 시간이 필요합니다. 수집기 관찰과 병행하는 동안 일봉 검증·로컬 학습을 진행하며, 기존 서버 재시작이나 실시간 설정 변경이 필요한 통합 검증은 11월 22일 마지막 휴장 기록과 관찰 보고서 생성 뒤에 진행합니다. [장중 수집 관찰 일정](../market-data/kis-session-observation-20261117.md)

**추가 Codex 크레딧·유료 초기화·GPU 대여 비용은 0원**으로 산정합니다. 기존 Plus 구독료는 별도이며, 유료 데이터 구매는 일정과 비용 산정 범위 밖입니다. 6~8단계는 과거 수급·공시·뉴스의 가용 시점과 공통 평가 표본을 확보할 수 있다는 전제입니다. 근거가 부족하면 해당 비교의 판정과 완료일을 보류하고, 확인된 범위에서 일정을 다시 산정합니다.

## 기준 모델과 학습 데이터

- **표본** — 2023-11-01~2026-11-02 삼성전자 KIS 원주가 일봉 730건을 확인했습니다. 동일 기간의 SK하이닉스도 730건을 확인했습니다. [공통 평가일 감사](hynix-daily-training-input.md) 거래일·휴장·정지, 중복·결측, 기업행사로 인한 가격 경계를 검사하고 포함·제외 사유를 기록합니다. 예상 거래일의 봉이 비어 있으면 더 뒤의 봉을 다음 거래일 정답으로 연결하지 않습니다. [KIS 가격 수집](../historical-data/replay/historical-price-acquisition.md) · [과거 기준정보의 검증 범위](../historical-data/replay/historical-reference-validation.md)
- **입력과 정답** — 거래일 T의 장 마감까지 확정된 값으로 다음 거래일 T+1의 `종가 ÷ 시가 − 1`이 양수일 확률을 추정합니다. 정답은 양수일 때 상승, 0 이하일 때 비상승입니다. 금요일에 신호를 만들었다면 다음 개장 거래일의 시가와 종가를 사용합니다. 따라서 당일 종가에서 다음 거래일 시가까지의 갭은 별도 사건 분석에서 다룹니다.
- **초기 특징** — 당일 시가 대비 종가 변화, 최근 1·5·20거래일 수익률, 당일 고저폭, 20거래일 변동성, 직전 20거래일 대비 거래량을 사용합니다. [계산식·결측 처리 규격](samsung-daily-training-input.md#특징과-정답-규격)
- **학습 방식** — CPU에서 L2 규제를 적용한 로지스틱 회귀를 종목별로 1개씩 학습합니다. L2는 가중치가 지나치게 커지는 것을 억제하고, 특징별 기여는 앱의 판단 근거에 활용합니다. Ryzen 5 5600X에서 합성 데이터 730행×20개 특징으로 측정한 CPU 한 스레드의 5회 학습·예측 중앙값은 **4.42ms**였습니다. 실제 일봉 검증·특징 생성·백테스트 시간은 2단계에서 따로 측정합니다. [로지스틱 회귀의 원리와 선정 근거](logistic-regression-baseline.md)

## 검증과 채택 기준

삼성전자에서 검증된 신호 후보를 시간순으로 60%·20%·20%에 배정한 뒤 경계를 넘는 정답 2건을 제외해 **학습 424건, 검증 141건, 최종 평가 142건**을 고정했습니다. 검증에서는 과거 학습 구간을 늘려가며 다음 구간을 예측하고 매수 관찰 임곗값을 정합니다. 다음 구간의 첫 신호일에 도달하는 학습 정답은 제외하고, 표준화 평균·표준편차는 각 학습 구간에서만 계산합니다. 모델과 임곗값을 고정한 뒤 최종 평가를 진행합니다. [고정 날짜와 제외 사유](samsung-daily-training-input.md#고정-날짜와-제외-사유) · [시계열 검증](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html) · [데이터 누수 방지](https://scikit-learn.org/stable/common_pitfalls.html#data-leakage)

| 평가 | 비교 기준과 기록 |
|---|---|
| 예측 | 학습 구간의 상승 빈도를 매일 출력하는 기준과 방향 적중률·로그 손실을 비교합니다. 로그 손실은 틀린 예측에 높은 확률을 부여할수록 커집니다. [로그 손실](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.log_loss.html) |
| 모의 전략 | 매일 시가 진입·종가 청산, 최근 5일 추세가 양수일 때만 진입, 거래하지 않음을 동일한 날짜·투입금·비용으로 비교합니다. 수수료·세금·체결 불리분, 비용 차감 수익률·최대 낙폭·거래 횟수, 높은 비용 가정에서의 변화를 기록합니다. [거래비용 대조](../execution-research/cost-statement-reconciliation.md) |
| 실제 거래일 앱 검증 | 과거 일봉 평가는 시가·종가 체결을 가정하며, 앱은 사용자가 주문할 때 조회한 시세로 모의 체결합니다. 두 결과를 각각 기록하고, 기존 4~5단계의 만료·중복·잔액·보유 수량·복구를 검증합니다. [모의매매 API](../contracts/api-spec.md#14-모의매매-api) |

예를 들어 시가 대비 종가가 0.2% 올라도 왕복 비용과 체결 불리분이 0.3%라면 비용 차감 손익은 약 −0.1%입니다. 이 값은 계산 예시이며 실제 비용은 확보한 근거와 가정을 평가 보고서에 기록합니다. 가격 기준 모델의 개선이 확인되지 않아도 테스트용으로 앱과 모의 원장을 검증할 수 있습니다. 전략 채택 여부는 독립 평가 결과를 보고 결정합니다.

## 투자자별 수급·공시·뉴스 비교 기준

- 수급은 두 보통주 각각의 종목코드·KRX 영업일·시장 범위를 일봉에 일치시킵니다. 개인·기관·외국인의 매수와 매도 원본을 보존하고, 단위와 분류가 일치하는 수량·대금에서 각각 `매수 − 매도`가 제공 순매수와 맞는지 검사합니다. 음수는 순매도입니다. 첫 특징은 투자자별 순매수 수량을 같은 범위의 전체 거래량으로 나눈 값으로 시작합니다. 장중 잠정치·장후 값과 수정 이력은 확인 가능한 범위에서 구분합니다. 신호 시각의 가용성이 확인된 수급만 사용하고 조회 누락·미확정과 실제 순매수 0을 구분합니다. [KIS 일별 수급 조회 예제](https://github.com/koreainvestment/open-trading-api/blob/main/examples_llm/domestic_stock/investor_trade_by_stock_daily/investor_trade_by_stock_daily.py) · [KIS 수급 응답 필드 예제](https://github.com/koreainvestment/open-trading-api/blob/main/examples_llm/domestic_stock/investor_trade_by_stock_daily/chk_investor_trade_by_stock_daily.py)
- 각 신호의 입력은 그 시각까지 사용할 수 있었던 정보로 구성합니다. 공식 공개 시각, 시스템 최초 확보 시각, 정정본 가용 시각을 보존합니다. 과거의 가용 시점을 입증할 수 없는 행은 해당 시점의 입력에서 제외하고, 수집 범위가 불완전한 날짜는 확인된 무사건 날짜와 구분합니다.
- 공시·기사 공개 전후의 가격 움직임은 별도 사건 분석으로 기록합니다. 발표 전 1~5거래일을 비교하고, 장 마감 뒤 발표는 당일 종가→다음 거래일 시가와 다음 거래일 시가→종가를 구분합니다. 공개 전 패턴을 시험할 때는 당시 가격·거래량과 이미 공개된 일정으로 신호를 만듭니다.
- 가격 특징·다음 거래일 시가→종가 목표·신호 기준 시각을 공통으로 사용하고, 각 비교에는 같은 학습·검증·최종 평가 날짜와 비용·체결 가정을 적용합니다. 공통 최종 평가 구간은 조정 전에 고정하며, 앞선 결과를 보고 모델이나 조건을 바꿨다면 새 독립 구간에서 평가합니다. 예측 확률의 로그 손실, 비용 차감 수익률, 최대 낙폭, 거래 횟수와 수급·사건별 표본 수를 비교합니다.
- 6단계에서는 수급, 7단계에서는 공시, 8단계에서는 뉴스와 수급 결합의 추가 효과를 확인합니다. 독립 평가에서 개선이 확인되면 채택을 검토하고, 개선이 없으면 기존 모델을 사용합니다. 공통 표본이나 가용 시점 근거가 부족하면 판정을 보류하고 부족한 기간과 자료를 기록합니다. [과거 공시 공개 시각과 정정 근거](../historical-data/corporate-actions/dart-historical-disclosures.md#공시-시각정정대상-증권) · [사건 처리와 전체 모델 범위](realtime-trading-roadmap.md#r6-학습-모델과-실시간-단기-전략)

## 실시간 기록과 재학습

확정 일봉으로 장 마감 후 추론하고 모델·입력 버전과 신호 시각을 기록합니다. 다음 거래일에 정답이 확정되면 해당 날짜를 재학습 후보에 추가합니다. 정답은 종목별로 거래일당 하나입니다. 체결·호가는 수집기 검증과 장중 분석에 활용합니다. 새 표본이 쌓이면 기존 자료와 함께 후보 모델을 학습하고 현재 모델과 독립 구간에서 비교합니다. 채택한 버전을 명시적으로 배포하고, 재시작 후 모델·기록 복구와 이전 버전으로 복귀할 수 있는지 검증합니다. 다종목 확대에서도 자금 배분·위험 한도·주문 통제는 Spring의 정책으로 적용합니다.
