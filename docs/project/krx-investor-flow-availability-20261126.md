## 신호 시점의 가용성

- KRX 개별종목 통계 화면의 안내는 정규장 집계 반영을 **15:45 예정**, 시간외를 포함한 최종 집계 제공을 **20:00 예정**으로 표시합니다. 이 시각은 KRX의 안내이며 KIS 일별 API의 실제 최초 제공 시각은 별도로 확인해야 합니다. [KRX 개별종목 통계 안내](https://data.krx.co.kr/contents/MDC/MDI/outerLoader/index.cmd?screenId=MDCSTAT023)
- 11월 26일 00:31~00:32 KST에 두 종목의 11월 25일 수급 행을 확인했습니다. 같은 시간에 11월 26일 당일자를 조회하자 HTTP 200 본문에 `OPSQ2001`과 `TIME LIMIT 00:00 ~ 15:40` 메시지가 돌아왔고 행은 없었습니다. 이 실행에서 확인한 것은 전일 행이 자정 이후에 조회됐다는 사실과 당일자 요청이 거절됐다는 사실입니다.
- 대상 KIS 행에는 거래일 `stck_bsop_date`와 `bold_yn`이 있었으나, 공식 응답 예제와 수신 원문에서 집계 공개·수정 시각이나 확정 여부를 확인할 수 있는 필드는 찾지 못했습니다. 기존 학습 기간의 일별 행에 대해 당시 20:15에 조회 가능했던 버전은 확인하지 못했습니다. [KIS 공식 응답 필드 예제](https://github.com/koreainvestment/open-trading-api/blob/main/examples_llm/domestic_stock/investor_trade_by_stock_daily/chk_investor_trade_by_stock_daily.py) · [현재 국내 신호 시각](daily-inference-integration.md#신호-생성과-만료)
