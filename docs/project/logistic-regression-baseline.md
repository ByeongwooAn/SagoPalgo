# 삼성전자·SK하이닉스 기준 모델의 로지스틱 회귀 설계

두 종목에 같은 입력 정의와 학습 절차를 적용한 뒤 종목별 표준화 통계, 가중치와 매수 관찰 임곗값을 따로 구했습니다. 종목마다 평소 거래량과 가격 변동의 분포가 다를 수 있으므로, 각 종목의 학습 자료로 그 종목의 기준을 정합니다. 비교할 때는 같은 최종 평가 날짜와 비용을 사용합니다. [두 종목 착수 순서와 평가 기준](learning-prototype.md#두-종목의-착수-순서와-평가-기준) · [실제 평가와 지표 해석](daily-learning-evaluation.md)

로지스틱 회귀는 **두 가지 결과 중 하나가 일어날 확률을 추정하는 모델**입니다. 날씨 앱이 여러 관측값으로 비가 올 확률을 계산하듯, 이 모델은 장 마감까지 확인한 가격과 거래량으로 다음 개장일에 **종가가 시가보다 높을 확률**을 계산합니다. 이름의 ‘회귀’는 입력 변수와 상승 오즈의 로그 사이의 관계를 추정하는 데서 나옵니다. 이 프로젝트에서의 용도는 이진 분류입니다. [scikit-learn 로지스틱 회귀](https://scikit-learn.org/1.7/modules/linear_model.html#logistic-regression)

## 무엇을 보고 무엇을 맞히는가

거래일 T의 장 마감 후 확정된 원주가 일봉으로 특징 일곱 개를 계산합니다. 같은 날짜에 이용할 수 있는 정보로 당일 움직임, 여러 기간의 추세, 변동성, 상대 거래량을 표현하도록 설계했습니다. [특징 계산식과 결측 처리](samsung-daily-training-input.md#특징과-정답-규격)

| 모델 입력 | 왜 넣었는가 |
|---|---|
| 당일 시가 대비 종가 변화 | 장이 열린 뒤 마감까지 가격이 어느 방향으로 얼마나 움직였는지 담습니다. |
| 최근 1거래일 종가 수익률 | 직전 종가와 비교해 최신 움직임을 담습니다. 당일 시가 대비 변화와 달리 개장 때 생긴 가격 차이도 반영합니다. |
| 최근 5·20거래일 종가 수익률 | 서로 다른 두 기간에 걸쳐 쌓인 가격 추세를 담습니다. 각 기간마다 값 하나를 계산합니다. |
| 당일 고저폭 ÷ 시가 | 종가가 시가 부근으로 되돌아온 날에도 장중 가격이 움직인 범위를 담습니다. |
| 최근 20거래일 변동성 | 종가 수익률의 표준편차로 최근 종가 변화의 전형적인 크기를 담습니다. |
| 직전 20거래일 평균 대비 당일 거래량 | 종목의 최근 거래량 수준에 비춰 그날 거래가 얼마나 많거나 적었는지 담습니다. |

학습할 때는 다음 개장일 T+1의 `종가 ÷ 시가 − 1`이 양수면 정답을 `1`(상승), 0 이하면 `0`(비상승)으로 둡니다. 예를 들어 다음 개장일 시가가 100, 종가가 101이면 정답은 `1`입니다. 실제 신호를 만들 때는 T까지의 특징으로 확률을 계산하고, 정답은 T+1 장 마감 후 확정합니다. 이 정의에서 확률 60%는 **다음 개장일 시가에서 종가까지 상승할 확률의 추정치**입니다. 가격 변화의 크기는 별도 정보가 필요합니다.

## 일곱 특징이 확률로 바뀌는 과정

**1. 특징의 단위를 맞춥니다.** 수익률과 거래량 비율은 숫자의 범위가 다릅니다. 표준화하면 각 값을 학습 구간의 평균에서 표준편차 몇 배만큼 떨어졌는지로 표현할 수 있습니다. 학습 평균이면 `0`, 학습 평균보다 표준편차 한 개만큼 높으면 `+1`입니다. 표준화에 쓰는 평균·표준편차는 매 학습 창에서 추정해 그 창의 검증·예측에도 적용합니다. [표준화](https://scikit-learn.org/stable/modules/generated/sklearn.preprocessing.StandardScaler.html) · [데이터 누수 방지](https://scikit-learn.org/stable/common_pitfalls.html#data-leakage)

**2. 특징별 점수를 더합니다.** 표준화한 특징 `z`에 학습한 가중치 `w`를 곱한 뒤 일곱 항과 절편 `b`를 더합니다. 절편은 모든 특징이 학습 평균에 있을 때의 출발 점수입니다.

`점수 s = b + w₁z₁ + w₂z₂ + … + w₇z₇`

**3. 점수를 확률로 바꿉니다.** 시그모이드 `p = 1 / (1 + exp(−s))`는 어떤 점수든 0과 1 사이의 값으로 바꿉니다. 점수가 0이면 50%, `−1`이면 약 27%, `+1`이면 약 73%입니다. `s`는 상승 확률을 비상승 확률로 나눈 값인 오즈 `p / (1 − p)`의 자연로그입니다. `w × z`는 **로그 오즈 점수에 더해지는 값**입니다. 확률이 얼마나 달라지는지 보려면 그 값을 더하기 전후의 점수를 각각 시그모이드에 넣어 비교합니다. [시그모이드와 로지스틱 회귀 식](https://scikit-learn.org/stable/modules/linear_model.html#logistic-regression)

가상의 장 마감일에 세 특징만 학습 평균과 다르다고 가정합니다. 숫자는 계산을 보여주기 위한 예시입니다.

| 항목 | 표준화한 값 | 가중치 | 점수 기여 |
|---|---:|---:|---:|
| 최근 5거래일 수익률 | 1.20 | 0.50 | +0.60 |
| 최근 20거래일 변동성 | 0.50 | −0.40 | −0.20 |
| 직전 20거래일 대비 거래량 | 0.50 | 0.20 | +0.10 |
| 나머지 네 특징 | 모두 0 | | 0.00 |
| 절편 | | | −0.10 |
| **합계** | | | **+0.40** |

`s = 0.40`을 시그모이드에 넣으면 상승 확률 추정치는 **약 59.9%**입니다. 예시에서 최근 5거래일 수익률이 점수를 가장 많이 높였고, 변동성은 점수를 낮췄습니다. 이런 방식으로 특정 날짜의 모델 출력을 설명할 수 있습니다. 서로 비슷하게 움직이는 특징은 기여를 나눠 가질 수 있고, 가중치는 학습 자료의 통계적 관계를 나타냅니다. [확률 보정과 신뢰도 확인](https://scikit-learn.org/stable/modules/calibration.html)

## 모델은 가중치를 어떻게 정하는가

모델은 과거 특징과 정답을 보면서 평균 **로그 손실**이 작아지도록 가중치와 절편을 맞춥니다. 실제로 상승하면 `−ln(p)`, 비상승이면 `−ln(1 − p)`만큼 손실을 계산합니다. 예를 들어 상승한 날에 80%를 예측하면 손실은 `−ln(0.8) ≈ 0.22`이고, 같은 날 20%를 예측하면 `−ln(0.2) ≈ 1.61`입니다. 틀린 방향에 높은 확신을 보일수록 손실이 커집니다. [로그 손실 정의](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.log_loss.html)

프로토타입은 로그 손실에 **L2 규제**를 더합니다. 가중치 제곱에 비례하는 비용을 학습에 포함해, 특정 특징이 과거 며칠을 잘 설명한다는 이유만으로 지나치게 큰 가중치를 얻는 일을 줄입니다. 예를 들어 다른 조건이 같다면 크기 2인 가중치는 크기 1인 가중치보다 제곱 벌점이 4배입니다. 최근 1·5·20일 수익률처럼 겹치는 정보를 담은 특징도 함께 넣은 채 가중치를 줄일 수 있습니다. 규제가 강하면 잡음에 덜 민감해질 수 있고, 지나치게 강하면 실제 신호까지 희석될 수 있습니다. [L2 목적함수와 규제 강도](https://scikit-learn.org/stable/modules/linear_model.html#logistic-regression)

## 왜 첫 모델로 골랐는가

한 종목의 일봉 730건에서 첫 학습 구간은 신호 424건, 입력은 특징 7개입니다. 로지스틱 회귀는 가중치 7개와 절편 1개로 여러 특징을 결합해 확률을 추정합니다. 인접 신호의 특징 창은 상당 부분 겹치므로, 424건이 서로 완전히 독립적인 사례 424개라고 가정하기 어렵습니다. 복잡한 비선형 규칙이 추가로 도움이 되는지는 첫 기준 모델을 세운 뒤 같은 조건에서 검증할 수 있습니다. [고정 표본과 평가 구간](samsung-daily-training-input.md#고정-날짜와-제외-사유)

표준화 통계, 가중치, 절편을 저장하면 앱에서 같은 특징의 확률과 항목별 점수 기여를 다시 계산할 수 있습니다. 가격 모델의 계산 구조를 고정하면 후속 단계에서 수급·공시·뉴스를 추가했을 때 입력 정보의 효과를 평가하기도 쉽습니다. 실제 자료에서 기준 모델이 얼마나 잘 작동했는지는 독립 평가에 기록했습니다. [2단계 평가 결과](daily-learning-evaluation.md)

### 실제 구현에 고정한 설정

| 설정 | 적용 이유 |
|---|---|
| 종목별 `StandardScaler` | 거래량 비율, 수익률, 고저폭 등을 학습 자료의 평균과 표준편차 단위로 맞춥니다. 그러면 입력 단위의 차이가 L2 규제에 미치는 영향을 줄일 수 있습니다. |
| `penalty="l2"`, `C=1.0` | 서로 겹치는 수익률 특징을 함께 쓰면서 큰 가중치에 벌점을 줍니다. `C`는 규제 강도의 역수이며, 첫 비교에서는 기본값 1.0을 고정해 재현 가능한 출발점을 만들었습니다. 규제 강도 탐색은 수행 범위에 없었습니다. |
| `solver="lbfgs"`, `max_iter=1000`, `tol=1e-9` | L2 목적함수를 최적화할 수 있는 scikit-learn의 기본 솔버를 사용했습니다. 반복 상한과 수렴 허용오차를 명시하고, 수렴 경고를 실패로 처리해 미수렴 결과의 평가를 막습니다. |
| CPU 한 스레드 | 두 종목을 동일한 로컬 실행 조건으로 재현합니다. |

학습·확률 출력·거래 결정을 구현한 위치와 scikit-learn 1.7 설정 정의입니다. [학습·평가 코드](../../AI/ai-server/app/replay/daily_learning.py) · [LogisticRegression 매개변수 정의](https://scikit-learn.org/1.7/modules/generated/sklearn.linear_model.LogisticRegression.html)

| 모델 | 잘할 수 있는 일 | 이번 자료에서 따져볼 점 |
|---|---|---|
| **상승 빈도 기준** | 학습 표본의 정답 중 상승의 비율을 모든 신호일에 같은 확률로 출력합니다. | 특징을 활용해 얻는 추가 정보가 있는지 로그 손실로 비교할 수 있습니다. |

| **랜덤 포레스트·그래디언트 부스팅** | 여러 트리로 임계점과 특징 간 상호작용을 학습합니다. 포레스트는 트리 예측을 평균하고, 부스팅은 앞선 모델의 오차를 줄이는 방향으로 트리를 더합니다. | 깊이·잎 크기·트리 수 등을 선택하고 확률 품질과 날짜별 근거를 별도로 확인해야 합니다. 비선형 패턴이 여러 검증 구간에서 반복되는지 살필 때 비교 가치가 있습니다. [트리 앙상블](https://scikit-learn.org/stable/modules/ensemble.html) |

| **신경망** | 여러 층에서 복잡한 상호작용을 학습할 수 있습니다. | 층 크기·규제·학습 설정에 따라 결과가 달라지고, 날짜별 출력도 여러 층을 거쳐 계산됩니다. 현재 한 종목의 7개 요약 특징에서는 복잡도를 추가할 만큼 검증 성과가 개선되는지부터 확인해야 합니다. [지도학습 신경망](https://scikit-learn.org/stable/modules/neural_networks_supervised.html) |

## 확률과 모의매매 판단을 어떻게 검증하는가

확률이 60%라고 나오면, 비슷한 확률을 받은 사례가 실제로 약 60% 상승했는지는 관측값으로 따로 확인해야 합니다. 가령 상승 확률이 60%인 상황에서도 평균 상승폭이 `+0.3%`, 비상승 때 평균 변화가 `−0.6%`라면 비용을 빼기 전 기대 변화는 `0.60 × 0.3% + 0.40 × (−0.6%) = −0.06%`입니다. 수치는 계산 예시입니다. 분류에 흔히 쓰는 50% 경계는 어느 방향의 확률이 높은지 가르는 기준입니다. 매수 관찰 임곗값은 검증 구간의 신호 결과와 거래비용 가정을 바탕으로 결정합니다. [확률 보정](https://scikit-learn.org/stable/modules/calibration.html) · [확률과 의사결정 임곗값](https://scikit-learn.org/stable/modules/classification_threshold.html)

1. **학습 424건과 검증 141건**을 시간순으로 나눴습니다. 검증을 47건씩 3구간으로 나누고 각 구간 첫 신호일보다 정답일이 앞선 자료만 그 구간의 표준화와 적합에 썼습니다. 미래 날짜의 가격과 정답이 과거 신호의 확률에 섞이는 일을 막기 위한 설계입니다. 매수 관찰 임곗값은 검증 구간의 예측을 모아 기본 비용 차감 누적 수익률로 골랐습니다. [시간순 교차검증](https://scikit-learn.org/1.7/modules/generated/sklearn.model_selection.TimeSeriesSplit.html)
2. 최종 모델은 최초 **학습 424건**의 표준화 통계와 계수를 사용하고, 검증에서 정한 진입 임곗값을 붙였습니다. 둘을 고정한 뒤 **최종 평가 142건**을 열어 판단했습니다. 예측에서는 학습 상승 빈도와 방향 적중률·로그 손실을 비교했습니다. 모의매매에서는 매일 진입, 5일 추세가 양수일 때 진입, 거래 없음과 같은 날짜·체결·비용 조건으로 대조했습니다.
3. 수수료·세금·체결 불리분을 반영한 수익률, 최대 낙폭, 거래 횟수를 기록합니다. 비교 기준보다 개선되는지는 이 독립 평가 결과로 판단합니다. [검증과 채택 기준](learning-prototype.md#검증과-채택-기준)
