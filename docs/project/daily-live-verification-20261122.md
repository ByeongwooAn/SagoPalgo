## 운영 환경과 대조 방법

1. `develop` 커밋 `afead49`로 AI·Spring을 빌드하고 로컬 운영 Compose의 두 서비스를 갱신했습니다. 교체 전 이미지에 복구용 태그를 남겼고, AI 컨테이너 안에서 네 모델의 파일과 소스에 고정한 SHA-256이 모두 일치하는지 확인했습니다. 직접 Spring API와 운영 Nginx 프록시를 통한 읽기 조회가 HTTP 200으로 응답했고, Windows 릴리스 실행본은 같은 루프백 프록시에 연결했습니다.
2. 20:46 KST에 KIS 원주가를 독립 조회했습니다. 네 종목 모두 10월 23일~11월 20일의 각 시장 연속 거래일 **21개**와 가격·거래량 범위를 확인했습니다. 기준 거래일의 OHLCV가 국내 기간별·일자별 두 API, 미국 기준일 지정·최신 두 조회에서 각각 일치했습니다. 미국의 두 조회는 같은 KIS API에 서로 다른 기준일 입력을 사용합니다.
3. 로컬 원주가와 고정 모델에서 7개 특징·기여값·확률을 계산했습니다. 20:47~20:48 KST에 운영 프록시의 국내 추천 상세 및 미국 신호에서 모델 해시, 입력 시작일, 기준일, 임곗값, 판정, 만료와 7개 기여값을 대조했습니다. 국내 두 종목은 기존 관심종목 분석으로 생성한 추천을 상세 API에서 다시 읽었고, 미국 두 종목은 시세 화면의 신호 조회 경로로 확인했습니다.
4. Windows 앱에서 삼성전자는 추천 이력 상세, SK하이닉스는 최신 추천, 애플·엔비디아는 **보유 → 미국주식 시세 조회 → 장 마감 모델**을 열었습니다. 기준 거래일, 확률, 판단 근거, 모델 버전과 한국 시간 만료를 화면에서 확인했습니다.
