## 특징과 정답 규격

`T`는 확정 일봉을 입력으로 하는 신호 거래일입니다. `O`, `H`, `L`, `C`, `V`는 원주가 시가·고가·저가·종가와 전체 거래량입니다. `T-n`은 KOSPI 개장일 기준으로 거슬러 올라갑니다. 특징은 아래 7개를 이 순서로 계산합니다.

| 특징 | 계산 |
|---|---|
| 당일 시가 대비 종가 변화 | `C[T] / O[T] − 1` |
| 최근 1·5·20거래일 종가 수익률 | `C[T] / C[T-n] − 1`을 `n = 1, 5, 20` 각각에 적용 |
| 당일 고저폭 | `(H[T] − L[T]) / O[T]` |
| 최근 20거래일 변동성 | `T−19`부터 `T`까지 일별 종가 수익률 20개의 모집단 표준편차. 첫 수익률에 `C[T−20]` 사용 |
| 직전 20거래일 대비 거래량 | `V[T] / mean(V[T−20], …, V[T−1])` |

입력 창은 `T−20`부터 `T`까지 개장일 21일입니다. 휴장일은 건너뛰고 개장일의 결측·비거래·가격 기준 불일치에는 보간이나 대체 값 없이 중단합니다. 주식 단위 변경 등으로 비교할 수 없는 가격 경계를 새로 발견하면 경계를 가로지르는 특징을 사용하기 전에 자료와 규격을 다시 검토합니다. 입력의 가격과 거래량은 모두 `T`까지 제한하고 사건·장중 표시와 목표일 정보는 특징에 넣지 않습니다.

정답은 **바로 다음 KOSPI 개장일 `T+1`의 `C[T+1] / O[T+1] − 1`**입니다. 이진 분류 값은 `C[T+1] > O[T+1]`일 때 1, 같거나 낮을 때 0입니다. 다음 개장일 봉이 없거나 유효하지 않으면 해당 정답을 사용할 수 없으며, 이후 봉으로 연결하지 않습니다. 사후 확보 일봉으로 날짜 단위 평가를 준비했습니다. 3단계의 실제 신호는 공급자의 확정 일봉을 확인한 뒤 생성합니다.
