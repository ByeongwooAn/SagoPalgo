## 일정의 조건과 재산정 기준

1. 후속 복구에서 공개 저장소와 실제 1,081행 표본을 확보했습니다. 세션 코드·시각 품질과 실제 체결 모형 대조는 남으며, 과거 CB 틱이나 전체 기업행사에 별도 자료가 필요할 수 있습니다.
2. KB 주문 조회·종결·소수점 계약의 회신 날짜는 미정입니다. 모의 자동매매 검증 종료까지 해소되지 않으면 실거래/소수점의 완료일은 **현재 확정할 수 없으며**, 영향 경로의 대기 기간만큼 기준 범위를 뒤로 옮깁니다. 무관한 작업과 겹친 대기를 모두 더하지는 않습니다.
3. 실제 보유 종목 계좌 대조, 권한/호출 예산, 장기 정상 운영·복구, 사용자 확인이 가능한 환경을 가정합니다. 자료 부재를 합성 테스트 통과로 대체하지 않습니다.
4. 이번 작은 입력 규격 작업만으로 5-08/09 전체 완료율을 올리지 않습니다. 향후 전체 조건 완료 또는 범위/환경 변경이 있을 때 갱신합니다.
5. **2주 간격 또는 큰 단계 완료 때** 실제 투입 시간·완료 조건·대기 사유를 기록해 남은 시간 추정을 갱신합니다. 모델 독립 평가가 기준에 못 미치면 전략 연구 기간을 추가하며 수익 목표 달성을 일정상 완료로 약속하지 않습니다.
