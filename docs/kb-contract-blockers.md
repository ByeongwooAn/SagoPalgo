# KB 계약 보류 목록과 재개 조건

기준일: 2026-11-02 · 사용자 설명: KB 문의 답변 대기 중. [지원·계약 매트릭스](trading-api-contract-matrix.md)의 미확정 항목을 관리합니다.

아래 질문은 기존 코드·문서에서 확인한 개발상의 질문 목록입니다. **모든 질문이 이미 KB에 발송되었다는 뜻은 아닙니다.** 실제 문의 번호·발송 원문·답변은 이 작업에서 확인하지 않았고 추가 메시지를 발송하지 않았습니다. 사용자가 받은 답변과 연결할 때 답변일·적용 상품/API·근거를 기록합니다.

## 1. 답변 전 유지할 경계

- UNKNOWN·전송 시작 이후 SENDING/DISPATCHING의 자동 종결·재전송·가드 해제를 추가하지 않습니다.
- 정정/취소 요청의 일부·전부 구분을 응답의 완료 코드로 사용하지 않습니다.
- 시뮬레이터의 FILLED/REPLACED/CANCELLED·가상 자원 상태를 실제 KB 계약으로 옮기지 않습니다.
- 기존의 검증된 전량 체결 대조, 반환 기록 복구, 전송 전 RESERVED 중단은 각각의 기존 조건을 유지합니다.
- 현재 허용하는 첫 일부/전량 변경을 넘어 추가 정정·부분 체결 후 변경·예약금 재사용을 열지 않습니다.
- 계좌 동기화 결과에서 주문이 보이지 않는다는 이유만으로 pending 주문을 해제하지 않습니다.

## 3. 현재 공개 근거와 코드 경계

2026-11-02 공개 상세 정의를 재조회해 `crct_cncl_ccd`, `crct_q`, `sor_cncl_q`의 description이 null임을 확인했습니다. 공개 자료 전체에 설명이 존재하지 않는다는 결론은 아닙니다. [SSQM2341 정의](https://openapi.kbsec.com/api/apis/catalog/66998ea3-85f3-4060-bf6d-f88a163eee35/tr-list)

반면 정정/취소 요청의 `crct_clsf`에는 일부/전부 구분이 기재되어 있어 현재의 첫 변경 요청에 사용합니다. 응답 완료 판정과는 다른 계약입니다. [정정 요청](https://openapi.kbsec.com/api/apis/catalog/28577def-666f-4d77-b9dc-5904db58ba49/tr-list), [취소 요청](https://openapi.kbsec.com/api/apis/catalog/48815fb5-53fd-4b58-905b-c04431a1e882/tr-list)

## 4. 답변을 받았을 때의 처리 순서

1. 공식 답변의 적용 API·상품·시장·계좌 유형·기준일을 해당 ID에 연결합니다. 계좌/주문번호·토큰 등은 제거합니다.
2. 답변이 요청 접수, 실제 체결, 취소 완료, 조회 반영 중 어느 시점을 설명하는지 분리합니다. 질문 일부만 해결됐으면 나머지는 보류합니다.
3. 완료/미완료/거절·부분 체결·지연·중복·역전 응답의 비식별 계약 fixture를 작성합니다. 문서에 없는 값은 거절/미확정으로 처리합니다.
4. `develop` 최신에서 기능별 브랜치를 생성해 기존 가드·원장·재시작 불변식을 유지하면서 필요한 판정만 구현합니다.
5. 계약/서비스·격리 MySQL·화면 연결을 검증합니다. 실제 계좌 검증과 제한 실주문은 별도 승인된 범위에서 수행합니다.
6. 실환경 결과·배포 버전·잔여 제약을 기록한 뒤 해당 보류 항목과 [진척도](development-progress.md)를 갱신합니다. 답변 수신만으로 기능 완료 처리하지 않습니다.

기록 형식: `ID / 답변일·출처 / 적용 범위 / 해결된 의미 / 남은 질문 / 코드·테스트 근거 / 배포·실환경 확인 / 상태`.

## 5. 답변 없이 진행할 범위

- **진행:** API/데이터 계약 설계, 원본 정밀도 보존, 계좌 스냅샷·조회 완전성, 수집 이벤트·체크포인트, 앱 관심목록, KIS 재접속·분봉, 뉴스/공시 증분 수집, 비용 포함 과거 재현·모의 운용.
- **조건부 진행:** 기존 계약의 실제 읽기 연결·한도/지연 측정은 별도의 실행 범위를 정한 뒤 수행합니다. 문서 조사 중 계좌 호출을 자동 실행하지 않습니다.
- **보류:** KB-01~04에 의존하는 실제 자동 종결·추가 변경·예약금 재사용·자동 전송 활성화, KB-05의 미확정 체결 조건을 전제한 소수점 단타.

구체적인 다음 구현 묶음은 [초기 실행 계획](initial-trading-policy.md#6-답변-대기-중의-실행-순서)에 연결합니다.
