# 사고팔고 프로젝트·AI 작업 단위별 진척도

국내 KOSPI·KOSDAQ을 우선하며, 구현 상태와 실제 계좌·시장 검증 범위를 함께 기록합니다. 단계별 범위는 [단계별 로드맵](realtime-trading-roadmap.md), 실행 순서와 완료 조건은 [남은 개발 작업](remaining-development-units.md)에서 관리합니다. 장중 복구·장기 관찰 상태는 2026-11-13 확인 결과를 반영했습니다.
