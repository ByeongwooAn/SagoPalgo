# U03 공식 호가 단위 팩

최신 후속: [U03 과거 호가 단위·엔진 연결 완료](historical-tick-rules.md). KOSPI 25/KOSDAQ 11개 판본의 동일 보통주 격자를 확인하고 과거 팩·엔진/CLI를 연결했습니다. 기존 실제 보고서 28개 바이트 보존·공식 격자 28개 사후 대조 확인. 미래 근거는 기본 차단하며 다음은 U04 실제 비용입니다. 고정 합계 27/48·56%, 5번 39% 유지. 아래 초기 U03 기록은 당시 범위입니다.

2026-11-06: 날짜·시장·상품·가격대·자료 가용 시각을 검사하는 팩과 독립 조회/가정 대조를 구현했습니다. **U03 전체는 진행 중**입니다. 현재 확정 팩은 법제처 안내의 작성 기준일인 **2026-10-15 하루의 KOSPI/KOSDAQ 보통주**입니다. 이 하루를 규정의 실제 시행 기간으로 오인하지 않습니다. 과거 전체 기간의 시행세칙 연혁과 연구 체결 엔진 연결은 남았습니다.

## 근거와 범위

[법제처 공식 안내](https://www.easylaw.go.kr/CSP/CnpClsMain.laf?ccfNo=2&cciNo=1&cnpClsNo=2&csmSeq=1701)는 유가증권시장 시행세칙 제32조와 코스닥 시행세칙 제18조를 인용하며 양 시장 7개 가격대의 단위를 제시합니다. 안내 자체는 법적 유권해석이 아니며 작성 기준일이 2026-10-15로 표시됩니다. 이를 과거 법령 판본이나 개정 시행일 증거로 대신하지 않았습니다.

| 가격 범위(원) | 호가 단위(원) |
|---|---:|
| 0 초과~2,000 미만 | 1 |
| 2,000 이상~5,000 미만 | 5 |
| 5,000 이상~20,000 미만 | 10 |
| 20,000 이상~50,000 미만 | 50 |
| 50,000 이상~200,000 미만 | 100 |
| 200,000 이상~500,000 미만 | 500 |
| 500,000 이상 | 1,000 |

공식 HTML 원본·수집 영수증은 `AI/ai-server/research-artifacts/official-ticks-20261106`에 보존합니다. 저장소에는 [스냅샷 팩](examples/official-tick-rules.json)과 [스키마](examples/official-tick-rules.schema.json)에 원문 SHA-256·출처·실제 수집 시각을 기록합니다. 팩 값은 해당 공식 표를 수동 대조한 값이며, 임의 외부 팩의 해시 문자열만으로 공식성을 인증하지 않습니다.

KRX 구 규정 사이트의 직접 열람은 403/시간 초과였고 새 포털의 기존 코스닥 시행세칙 제2304호 캐시에서는 제18조의 동일 표를 확인했습니다. 이 단일 판본만으로 양 시장·전 기간의 법적 연속성을 선언하지 않았습니다. ETF/ETN/ELW·소수점·NXT·시간외 특수 가격 결정은 보통주 표로 대체하지 않습니다.

## 구현과 실행

`app.replay.tick_rules`의 엄격한 스키마는 가격대 누락/겹침·날짜 역전·같은 상품의 적용 기간 충돌·중복 ID를 거절합니다. 조회는 날짜 `[validFrom,validTo)`와 가격 `[lower,upper)`를 사용합니다. 수집 시각보다 과거의 known-at 요청, 범위 밖 날짜·상품·시장·비정상 가격은 차단합니다. 가격이 단위에 맞지 않아도 자동으로 반올림하거나 주문을 전송하지 않습니다.

AI 서버 폴더에서 실행하는 예:

```powershell
.\.venv\Scripts\python.exe -m app.replay.tick_rules --pack ../../docs/examples/official-tick-rules.json --market KOSPI --product COMMON_STOCK --date 2026-10-15 --price 200000 --known-at 2026-11-07T00:00:00Z --assumed-tick 100 --output research-artifacts/tick-comparison.json
```

결과는 공식 표 단위 500, 기존 가정 100과 불일치입니다. 예시 known-at은 팩 수집 후의 조회 기준을 뜻하며 실제 과거 가용 시각이 아닙니다. 출력은 덮어쓰지 않습니다. 기존 `QuoteExecutionPolicy.tickSize`·보고서·가격/비용 계산은 유지하고, 독립 도구에서 먼저 비교합니다. `coverageComplete=false`, 거래/전략 검증 사용 불가를 유지합니다.

## 검증과 다음 실행 단위

신규 테스트 34건에서 양 시장 모든 가격 경계 전후·가격 정렬·효력 구간 끝의 제외·자료 확인 전 조회·미지원 상품·비정상 가격·겹침/누락을 확인했습니다. 전체 회귀는 1,229건 통과·Java/MySQL fixture 환경 조건 1건 제외였고, 해당 1건은 fixture를 명시한 별도 실행에서 통과했습니다. 합계 고유 테스트 1,230건을 검증했습니다. 기존 의존성 경고 1건입니다. 이번에 계좌·주문·DB·운영 수집·EXE는 변경하지 않습니다.

현재 요청의 남은 작업은 다음 하나의 묶음입니다: **고정 과거 범위의 양 시장 시행세칙 연혁 확보·본문/부칙 대조 → 확인된 구간 팩 생성 → 엔진의 가격별 호가 단위 독립 대조 연결 → 실제 저장 자료와 전체 회귀**. 완료 조건은 2023-11-01~2026-11-02 보통주의 근거 없는 적용 구간을 명시적으로 해소/제외하고 경계 검사와 재현 결과를 남기는 것입니다. 단일 안내 스냅샷으로 U03 완료를 체크하지 않습니다.

U04 실제 비용·세금 팩은 그 이후의 별도 작업이며 KB 적용 조건 확인이 필요합니다. U05 독립 체결 대조는 호가 단위와 비용 근거를 함께 사용합니다. 프로젝트 고정 완료율 27/48·56%, 5번 7/18·39%, 5-08 진행 중을 유지합니다.
