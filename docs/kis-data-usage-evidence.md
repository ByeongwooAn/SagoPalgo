## 조사 범위와 한계

포털 화면의 공개 호출 경로를 확인해 고객/제휴 약관과 [공개 FAQ](https://apiportal.koreainvestment.com/community/10000000-0000-0011-0000-000000000002)를 익명 GET으로 읽었습니다. 로그인·비공개 게시판·고객 계정 정보는 사용하지 않았습니다.

FAQ의 제목/본문 검색에서 AI·인공지능·머신러닝·학습·저장·보관은 각각 결과 0건, 시세는 16건이었습니다. 시세 결과 중 개인 웹페이지·제휴기관·기간별 조회의 공개 답변을 확인했습니다. 검색 결과 0건은 다른 표현·로그인 자료·고객별 약정에 안내가 없다는 증거가 아닙니다. 검색엔진의 포털 공식 결과도 대조했습니다.

공개 고객 약관에서 AI 모델 학습의 개별 허용 조건, 고객 로컬 DB의 시세 보관 상한, 가공 특징/학습 가중치의 취급을 직접 정한 문구는 확인하지 못했습니다. 따라서 현재 trainingRightsConfirmed=false를 유지합니다. 실제 수집/대조의 완료 여부와 별개인 활용 범위 확인 항목입니다.

원문 조회 결과와 검색 응답은 Git 제외 `AI/ai-server/build-codex-replay/kis-public-terms/`에 조사 증거로 보관합니다. Git에는 전문을 복제하지 않고 링크·조항별 요지만 기록합니다.

## KIS에 확인할 문의 초안

아래는 검토용 초안이며 발송하지 않았습니다. 계좌번호·앱키·토큰을 포함할 필요가 없습니다.

> 개인 고객이며 본인 자산 운용을 위한 프로그램을 직접 개발하고 있습니다. KIS Open API 국내 주식 시세를 이용할 때 다음 범위가 고객 이용약관 제5조③의 개인 업무 이용에 포함되는지 확인 부탁드립니다.
>
> 1. 과거 원주가 일봉/분봉을 본인 PC 또는 본인 전용 서버에 저장해 장기간 분석·백테스트에 사용하는 경우, 허용 보관 기간·자료량·별도 신청 조건이 있나요?
> 2. 자료를 외부에 제공하지 않고 본인 전용 머신러닝 모델을 학습·추론해 본인 투자 판단에만 사용하는 것이 가능한가요?
> 3. 원시세·가공 특징·학습 가중치/모델의 저장·삭제·이용 조건은 각각 어떻게 되나요?
> 4. 외부 LLM/클라우드 API로 시세를 전송하는 경우는 로컬 학습과 달리 취급하나요? 필요한 별도 동의/계약이 있나요?
> 5. 추가 시세정보 이용계약이 필요하다면 개인 고객의 어떤 이용 범위부터 필요한지와 확인할 약관/담당 부서를 안내 부탁드립니다.

공식 답변을 확보하면 해당 범위·출처·시각을 원래 수집 당시의 미확인 기록과 별도로 연결합니다. 단순히 검색에서 금지 문구가 없다는 이유로 학습 허용 플래그를 켜지 않습니다. 독립적으로 진행할 수 있는 데이터 검증·달력/기업행사 정합성 도구와 활용권 확인은 구분해 관리합니다.
