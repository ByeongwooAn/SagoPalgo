# H05 2024년 1~3월 배당 지급 후보 39건 대조

세이브로 지급일이 일치한 4,343건에서 2024년 1~3월 지급으로 표시된 **39건**을 검토했습니다. 코스피 33건과 코스닥 6건이며 월별로 1월 3건, 2월 7건, 3월 29건입니다. 지급일은 발행사가 해당 회차의 지급 완료일을 보고하거나 공식 과거 지급 내역에 일자를 명시한 경우에 확인했습니다. [전체 후보 원장](historical-dividend-payments.md)

세 필드가 모두 일치한 **2건**은 맥쿼리인프라와 ESR켄달스퀘어리츠입니다. 유한양행은 후속 보고서에 실제 지급일을 기재했으며 세이브로와 하루 차이가 있습니다. 전 기간 누계는 **30건 확인 · 87건 원문 검토 후 미확정 · 4,226건 원문 미연결**입니다.

KIND에서 종목별로 2023-09-01~2024-08-31의 목록을 확인했습니다. 미래에셋글로벌리츠는 목록 표시일과 접수번호 날짜가 다른 행이 있어 조회 기간과 제목을 좁혀 확인했습니다. 배당·분배 결정 39건, 지급 후 정기·지배구조보고서와 기타신고사항 102건, 발행사 IR 원문 3개를 연결했습니다. 보고서 본문에 지급 예정일 또는 기간의 지급 내역만 있는 경우 실제 일자의 미확인 사유를 기록했습니다. - **유한양행**의 보통주 450원 결산배당은 2024년 1분기·반기보고서에서 3월 28일 지급 완료로 기재했습니다. 세이브로의 3월 29일과 하루 차이가 있으며 그 원인은 확인되지 않았습니다. [1분기보고서](https://kind.krx.co.kr/external/2024/05/16/002036/20240516004750/11013.htm) · [반기보고서](https://kind.krx.co.kr/external/2024/05/31/000428/20240531000834/99667.htm)

- 공시의 총배당금과 배당 대상 주식 수로 계산할 수 있는 6건은 소수점 아래 열 자리까지 반올림하고 공시의 정수 표기를 병기했습니다. **롯데리츠**의 23,234,198,171원과 242,968,884주로 계산한 95.6262291224원은 세이브로 95.62617871원과 다릅니다. **이리츠코크렙·코람코라이프인프라리츠·코람코더원리츠**는 공시 정수 표기와 세이브로 표시가 같으며 산식값에서 차이가 납니다.
- **미래에셋맵스리얼티**는 2월 20일 정정에서 265원을 확정하고 2월 29일 지급 일정과 변동 가능성을 기재했습니다. KIND의 지급 후 영업보고서 제출 공시 본문에는 실제 지급일이 없습니다.
