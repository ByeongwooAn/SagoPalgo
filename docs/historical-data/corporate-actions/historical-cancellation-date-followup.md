## 대조 방법과 범위

- KIND의 보통주 코드와 변경상장 수량·상장주식총수를 사용했습니다. 상장일 KRX 목록에서 해당 시장의 보통주 코드·ISIN을 확인하고 KIND 접수·상장일·상세 발행일과 각 소스 해시를 보존했습니다. [KRX 과거 종목 목록](../universe/krx-universe-history.md)
- 세이브로는 종목코드로 연결한 발행사를 조회해 변경상장일·보통주·소각 사유·감소 수량을 대조했습니다. 발행사별 조회 건수와 상세 행 수를 맞췄습니다. 분할 기록은 앞선 감사에서 발행사·시장·상장일에 해당하는 상세 행이 하나일 때 전체 감소 합계를 확인했습니다. 휴마시스는 발행사 검색 화면에서 코드로 확인했습니다. [세이브로 증권발행내역](https://seibro.or.kr/websquare/control.jsp?w2xPath=/IPORTAL/user/company/BIP_CNTS01012V.xml&menuNo=282)
- OpenDART의 2026-11-16 접수분까지 발행사별 목록 126페이지·7,490행을 조회했습니다. 사건 직후 정기보고서와 최초 사업보고서, 소각 결정·정정 공시를 골라 원문 ZIP 409개를 검토했습니다. 원문 ZIP을 반환하지 않은 3개 분기보고서는 DART 뷰어의 주식 총수·자본금·재무제표 주석 12개 절로 대조했습니다. 케이프와 한국알콜은 뷰어에서도 반기보고서의 날짜를 확인했고, 한솔아이원스의 해당 분기보고서는 수량을, 반기보고서는 소각일을 명시했습니다. [OpenDART 공시검색](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS001&apiId=2019001) · [케이프 분기보고서](https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20261116000650) · [한국알콜 분기보고서](https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20261116000716) · [한솔아이원스 반기보고서](https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20260813001023)
- 발행사 결정 공시의 예정일, 발행사 완료 보고, 세이브로의 발행일, KIND 상세 발행일과 변경상장일을 각각 기록했습니다. 원문의 캡처 시각과 당시 최초 공개 시각도 별개로 다룹니다. 결과는 연구용이며 당시 공개 시각이 확인되기 전에는 학습·거래 입력으로 쓰지 않습니다.
