## 검증과 다음 작업

- 세이브로를 재조회해 배당내역 4행과 지급일정 2행의 원래 행 해시가 동일함을 확인했습니다. 신규 응답 14개와 기존 상세 화면 정의의 해시를 대조했습니다. OpenDART 발행사 검색 2개와 선택 문서의 응답 23개를 검증했습니다. 이 중 2024-03-13 시알홀딩스 사업보고서의 첨부정정 1개는 공급자 응답 `014`를 기록했습니다. 배당 결정·주총 결과·후속 보고서 본문에서 회차를 확인했습니다.
- 네트워크를 차단하고 원장을 재생성해 게시본과 일치함을 확인했습니다. 기존 기업행사 전체 대조 보고서의 오프라인 감사와 관련 테스트 **57건**을 통과했습니다. 원문 영수증과 재생성 스크립트는 AI 서버의 `research-artifacts/h05-ambiguous-dividend-20261118` 및 기존 연구 경로에 있습니다.
- 이 4행은 기존 지급일 표시 일치 집합 4,343건의 밖에 있습니다. 두 회차의 일 단위 실제 지급일, 공급자 집계 차이 28건, 과거 최초 공개 시점은 미확인입니다. 기존 실제 지급 확인 241건과 **5-08 진행 중** 상태를 유지합니다. [기존 고정 지급 원장](historical-dividend-payments.md)
