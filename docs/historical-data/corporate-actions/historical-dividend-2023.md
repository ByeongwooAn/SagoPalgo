# H05 2023년 배당 지급 후보 29건 대조

세이브로에서 지급일 표시가 일치한 4,343건 가운데 **2023년 지급 후보 29건**을 모두 검토했습니다. 코스피 26건과 코스닥 3건의 각 행에 기준일·실제 지급일·보통주 주당액의 출처 또는 미확인 사유를 기록했습니다. [기존 4,343건 감사](historical-dividend-payments.md)

| 필드 | 세이브로와 일치 | 차이 | 미확인 |
| --- | ---: | ---: | ---: |
| 배당 기준일 | 29 | 0 | 0 |
| 발행사가 보고한 실제 지급일 | 4 | 1 | 24 |
| 보통주 주당액 | 28 | 1 | 0 |

세 항목이 모두 일치한 **4건**은 한샘·KB금융·HD현대·우리금융지주입니다. 2023년 후보 29건의 원문 검토를 마쳤으며, 실제 지급일이 미확정인 후보는 25건입니다. 전 기간 누계는 **실제 지급 확인 28건, 원문 검토 후 미확정 50건, 원문 미연결 4,265건**입니다.

KIND 종목코드별 목록을 2023-07-01~2024-06-30 범위에서 조회하고 각 발행사의 배당 결정 29건과 지급일 이후 정기보고서 62건을 대조했습니다. 목록의 공시 접수일과 표시일이 다른 행 때문에 목록 검증이 실패한 3사는 보고서 제목이나 배당 결정 전후 기간을 좁혀 다시 조회했습니다. 발행사 IR 페이지 8개를 원문에 연결했습니다. SK리츠 IR은 인증서 체인 오류, 삼성FN리츠 IR은 응답 시간 초과로 본문을 확보하지 못했습니다. 두 종목의 KIND 배당 결정과 지급 후 정기보고서는 확인했습니다.

- **삼성전자** IR은 11월 20일을 예정일로 공고했습니다. 지급 후 공지에서 확인되는 날짜는 배당내역 조회 서비스 종료일입니다. [삼성전자 배당 공고](https://www.samsung.com/global/ir/reports-disclosures/public-disclosure-view.84088/) · [배당내역 조회 공지](https://dividend.samsung.com/notice/BOARD_000000084)
