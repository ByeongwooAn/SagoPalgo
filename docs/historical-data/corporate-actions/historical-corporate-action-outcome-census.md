# H05 배당 지급·소각 완료와 거래소 공지 대조

후속 검토에서 발행일이 비었던 코스닥 14행의 소각일을 확인했습니다. 발행사 보고 13행과 예탁결제원 기록 1행을 구분합니다. [코스닥 소각일 후속 대조](kosdaq-cancellation-date-evidence.md)

효력일 범위는 **2023-11-01~2026-11-02 KOSPI·KOSDAQ 보통주**입니다. [이전 H05 후보 목록과 당시 종목군 대조](historical-corporate-action-event-audit.md)를 바탕으로, 지급일 표시와 실제 지급 보고, 소각 관련 발행일과 대상 주권, 정지일과 거래 재개를 각각 나눴습니다.

## 배당 지급

세이브로의 배당내역 전체검색과 대금지급일정을 양 시장·연도별로 대조했습니다. 배당내역은 기준일 2023-01-01부터 조회해 2023-11-01 직전의 기준일이 지급일 범위에 걸치는 경우를 포함했습니다. 조회 결과에서 **보통주·현금 지급액이 양수인 행**을 고르고, 지급일정의 시장·종목코드·지급일이 1대1로 일치하는지 검사했습니다. 세이브로 배당 화면은 확정 전 내역이 포함될 수 있다고 안내합니다. 같은 종목·지급일에 복수 대응 후보로 남았던 **4행**은 시알홀딩스 결산배당과 스톰테크 중간배당의 두 회차에 연결했습니다. 두 종목 모두 차등 주당액과 차등 시가배당률이 같은 회차의 배정 상세에 있고 날짜가 있는 지급 차수는 1차입니다. [4행 회차 대조](historical-dividend-ambiguous-schedule.md)

지급일이 비어 있던 **6행**은 리츠의 주총 승인 전 3행, 무배당 2행, 지급예정일과 사후 지급 총액 확인 1행으로 판정했습니다. 지급일 표시가 기간 밖인 157행은 시작일 전 146행과 종료일 후 11행입니다. [지급일 누락 대조](historical-dividend-missing-payment-dates.md)

## 소각과 거래소 조치

고정 주식발행내역에서 소각 사유가 명시된 상세 조회 **997행을 모두 확보**했습니다. 상세 화면의 시장·회사·상장일·상장방식·사유·수량을 목록과 대조했습니다. 상세 화면에는 발행일과 상장일이 별도 표시되고, 주권 종류는 표시되지 않습니다. 변경상장 공지에서 보통주·종목코드와 전후 수량을 읽어 상세 화면과 대조하며, ISIN은 공지에 적힌 경우에 기록합니다. 발행일이 비어 있던 코스닥 14행의 경우 대응하는 변경상장 공지를 별도로 대조했습니다. [KIND 주식발행내역](https://kind.krx.co.kr/corpgeneral/stockissuelist.do?method=loadInitPage)

| 소각 상세 대조 결과 | 행 수 |
| --- | ---: |
| 보통주·수량·소각일이 변경상장 공지와 상세 화면에서 일치 | 15 |
| 보통주·수량은 변경상장 공지에서 확인하고 날짜는 상세 화면에서 확인 | 1 |
| 보통주 코드·수량은 일치하나 두 원문에 날짜 없음 | 14 |
| 상세 화면의 발행일은 확인했으나 주권 종류는 미확인 | 962 |
| 발행일이 지정 범위 밖 | 5 |
| **합계** | **997** |

15행에는 이전에 확인한 삼성전자 보통주 1행이 포함됩니다. 상세 조회 범위는 **변경상장일**에 고정돼, 기간 말 소각 후 범위 밖에 상장된 사건은 별도 확인이 필요합니다.

KIND 원문 **99건**은 2023년 11월 권리락·배당락·거래정지·해제 후보 62건, 2023년 11~12월 소각 관련 상장 공지 23건, 상세 발행일이 누락된 소각 14건입니다. 권리락·정지·해제 등에서 공지 필드를 확인한 31건과 정지 기간 변경 전후 문구를 확인한 6건을 분리했습니다. 주권 종류가 명시되지 않은 KOSPI 공지 3건은 정지·해제 날짜만 보존했습니다. 본문 양식·대상 주권 또는 해당 필드를 확인하지 못한 23건과 변경상장 상세를 연결하지 못한 3건을 따로 기록했습니다.
