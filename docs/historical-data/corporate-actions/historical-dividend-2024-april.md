# H05 2024년 4월 배당 지급 후보 1,130건 대조

세이브로 배당내역과 대금지급일정이 일치하는 4,343건에서 2024년 4월 지급 후보 **1,130건**을 검토했습니다. 코스피 536건과 코스닥 594건이며, 같은 종목의 두 배당 회차는 세이브로 원본 행 해시로 구분했습니다. 기존 확인 3건과 검토 후 미확정 4건의 판정을 보존했습니다. [고정 후보 원장](historical-dividend-payments.md)

**전체 행별 결과**는 한 줄에 한 후보를 담습니다. 각 줄에서 시장·종목코드·세이브로 행 해시와 `fields` 아래 세 필드의 발행사 값, 세이브로 표시 값, 근거 링크 또는 미확인 사유를 찾을 수 있습니다. [1,130행 결과](../../examples/h05-2024-april-dividend-rows.jsonl) · [원문 검토 명세](../../examples/h05-2024-april-dividend-payments.json)

| 배당 기준일 | 1,127 | 0 | 3 |

세 항목이 일치한 **33건**에는 기존 판정 3건과 신규 30건이 포함됩니다. 나머지 **1,097건**의 사유와 출처를 기록했습니다. 기존 한국쉘석유의 보고서 내 날짜 충돌과 카카오뱅크의 발행사·세이브로 날짜 차이는 기존 판정과 근거를 유지했습니다.

## 검토 범위

OpenDART의 시장별·발행사별 공시 목록 335페이지를 고정했습니다. 지급 후 정기보고서의 시장별 조회 범위는 2024년 4~9월이며, 2024년 6월 결산 반기보고서를 우선했습니다. 에이치엔에스하이텍과 서울보증보험은 발행사별 사업보고서와 후속 보고서로 보완해 미연결 1,123행 전부에 정기보고서 원문을 연결했습니다. 네이버는 공식 통합보고서에서 지급 완료 문구를 확인했습니다. [금융감독원 공시검색·원본 안내](https://opendart.fss.or.kr/guide/main.do?apiGrpCd=DS001)

배당·분배 결정은 2023년 11월~2024년 5월 거래소공시 목록에서 대상 종목과 회차의 기준일로 연결했습니다. 조회한 결정·정정 원문은 1,277개이며 4개 접수번호는 OpenDART의 원본 파일 없음 응답을 보존했습니다. 지급 예정일, 주총·이사회 결의일, 지급월만 적힌 기록에는 실제 일자를 지정하지 않았습니다.

- **삼성FN리츠**는 공시의 72원 정수 표시와 총배당금·주식 수의 비율 72.3710970763원을 확인했습니다. **HD현대마린솔루션**의 2023년 결산 지급총액 800억 원과 지급 시점 유상증자 전 4,000만 주의 비율은 2,000원입니다. 기준일은 반기보고서에서 지급 회차의 명시적 기준일을 확인할 수 없어 미확인으로 남겼습니다. ## 오프라인 재검증

AI 서버 디렉터리에서 `requirements-dev.txt`를 설치한 가상환경으로 실행합니다. OpenDART 목록·원본 ZIP, 네이버 통합보고서, 수집 영수증, 세이브로 부모 보고서의 해시를 검증합니다. 행별 결과는 저장소에 포함되며 원본과 영수증은 로컬 연구 디렉터리에 보관합니다. DART 접수일과 관측 시각을 분리했고, 과거 최초 공개 시각은 H06에서 검증합니다. 감사 결과의 학습·거래 사용 가능 상태는 `false`입니다.

~~~powershell
$py = '.\.venv\Scripts\python.exe'
$options = @('--manifest', '../../docs/examples/h05-2024-april-dividend-payments.json',
             '--rows', '../../docs/examples/h05-2024-april-dividend-rows.jsonl',
             '--artifacts', 'research-artifacts', '--job', 'research-artifacts/h05-dividend-2024-april-20261117')
& $py -m app.replay.historical_dividend_april build @options
& $py -m app.replay.historical_dividend_april audit @options
~~~
