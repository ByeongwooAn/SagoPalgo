기준일: 2026-11-03. [대상 시장 거래시간·달력](../sessions/kb-historical-market-evidence.md)에 이어 현재 법인 연결을 검증하고 실제 3년 공시 목록과 선택 원문을 확보했습니다. **공시 목록 확보와 실제 상장/기업행사 효력 확정은 구분합니다.** 5-08 전체는 진행 중이며 고정 체크리스트는 **7/18·39%**를 유지합니다.

후속: [두 원문의 날짜 역할·금액/수량·정정 사실](corporate-action-facts.md)을 추출했습니다. 새 원문 1건을 추가하고 수치 8필드·날짜 6필드를 대조했으며 직접 부모 후보 2개는 미확정으로 남겼습니다. 아래 266건은 당시 결과이며 최신 전체 검증은 291건입니다. 실제 완료/효력 이벤트 연결은 후속입니다.

## 자료 계약

공식 개발가이드의 다음 범위만 조회합니다. API 키가 필요한 연구용 읽기이며 외부 AI 호출·시세 전송은 없습니다.

| 공식 근거 | 이번 사용 범위 |
|---|---|
| [기업개황](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS001&apiId=2019002) | 요청한 법인번호의 현재 종목코드·법인구분이 대상과 맞는지 확인 |

| [공시서류원본파일](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS001&apiId=2019003) | 감사된 목록 안에서 명시적으로 지정한 접수번호 1건의 원본 ZIP |

현재 기업개황은 과거 전체 상장 상태를 입증하지 않습니다. 공시 제목·현재 법인구분·종목코드나 설립일을 이용해 과거 상장/폐지 시점을 만들지 않습니다. B/I 이외 공시 유형·계열사 전체·시장 전체 종목군·모든 기업행사를 수집 완료한 것도 아닙니다.

## 일봉과 연결한 제한 수집

[dart_history.py](../../../AI/ai-server/app/replay/dart_history.py)의 plan은 기존 일봉 수집을 감사하고 개인용 범위 기록을 검사한 뒤 historyPlanId·dailySha256·종목·조회 기간을 고정합니다. 법인번호는 명시 입력하고 실제 기업개황의 종목코드가 다르면 추가 공시 요청 전에 중단합니다.

- plan/audit는 네트워크 없는 파일 검사입니다. collect만 기존 OpenDART enabled·API key 환경변수를 읽습니다. `.env` 자동 로드나 앱 설정 변경은 없습니다.
- 공식 HTTPS의 고정 경로를 사용하고 리디렉션을 차단합니다. 키는 공식 API 규격의 인증 쿼리에만 넣고 계획·요청 영수증·로그에는 저장하지 않습니다. HTTP 오류와 인증키를 포함한 응답은 고정 오류로 처리합니다.
- 요청 전에 저널에 예약·순번·키 지문을 남깁니다. 회사 조회와 모든 공시 페이지/실패 시도를 합쳐 계획 예산 안에서만 실행합니다. 기본 12회·최대 64회, 요청 사이 기본 최소 1초, 개별 요청 20초·2 MiB 제한입니다.
- 페이지당 100건, 접수일 오름차순, `last_reprt_at=N`을 고정합니다. 회사·종목·기간·페이지 번호/크기/총량·중복 접수번호·내용 충돌을 검사합니다. 총량이 바뀌거나 불완전 페이지면 완성 목록을 발행하지 않습니다. 공급자 조회 결과는 시점이 다른 페이지들의 관측이며 독립된 원자적 과거 스냅샷이라고 표시하지 않습니다.
- HTTP 실패 후 자동 반복은 없습니다. collect를 명시적으로 재실행하면 검증된 성공 요청은 재사용하고 미확보 요청만 남은 예산에서 재시도합니다. 실패/미확정 예약도 호출 수에 포함합니다. 예산이나 키 범위를 바꿔 같은 계획의 호출 수를 초기화하지 않습니다.
- `013`은 해당 조회의 결과 없음으로 보존하고 다른 오류와 구분합니다. 이를 모든 기업행사 없음으로 해석하지 않습니다. 수집/감사는 같은 작업 잠금으로 중복 실행을 막습니다.

이 예산은 해당 연구 작업의 예산이며 다른 앱/프로세스까지 포함한 계정 전체 한도 관리가 아닙니다. 기존 운영 수집·실주문 스위치는 변경하지 않았습니다.

## 공시 시각·정정·대상 증권

모든 수집 행은 원문 행 해시·접수번호·공식 링크·조회 유형·접수일·현재 확보 시각을 보존합니다. 접수일은 DATE 정밀도이며 `publishedAt=null`, `knownAt=observedAt`입니다. 접수번호에서 시각이나 날짜를 만들어내지 않고 공급자의 접수일 필드를 그대로 사용합니다.

정정 제목과 `rm`의 정정/철회 표시는 유지하지만 부모 접수번호를 추측하거나 이전 공시를 삭제하지 않습니다. 정정 관련 표시는 정정본 자체와 후속 정정이 있다는 공급자 표시를 포함할 수 있으며 동일한 의미의 확정 수정 횟수가 아닙니다. 원문 정정 계보·철회 효력 확정은 후속입니다.

배당·합병·회사분할·주식분할/병합·상장·상장폐지·정지·자본변경·자기주식/소각 제목을 검토 후보로 분류합니다. 이 분류는 보조 키워드 분류이며 기업행사 전체를 빠짐없이 확정한 목록이 아닙니다. 분류되지 않은 공시도 보존하고 모든 행은 원문 검토 상태를 가집니다.

해외 증권시장이나 종속/자회사가 제목에 나타나면 별도 `instrumentScope`로 기록하고 나머지도 국내 보통주로 확정하지 않고 UNVERIFIED로 둡니다. 회사분할을 주식분할 비율로 바꾸거나 해외 상장폐지를 KRX 종목 제외로 반영하지 않습니다. `effectiveDate=null`, `parentReceiptNumber=null`, `reviewState=ORIGINAL_DOCUMENT_REQUIRED`이며 기준정보 이벤트·가격 조정은 생성하지 않습니다.

## 선택 원문

[dart_documents.py](../../../AI/ai-server/app/replay/dart_documents.py)는 원문 별도 명령입니다. 수집 완료·감사된 목록에 있는 접수번호만 허용하고 목록 계획/자료 해시·법인/종목·대상 증권 표시와 원문을 연결합니다.

- 원문 1건의 예산은 별도 GET 1회입니다. 사전 예약과 실패 상태를 보존하고 완료 파일은 해시/ZIP 검사를 거쳐 재사용합니다. 다른 접수번호나 목록 버전으로 같은 보관 폴더를 재사용하지 않습니다.
- ZIP은 파일 수 32개·합산 비압축 32 MiB·개별 파일 8 MiB, 중복·암호화·잘못된 경로를 검사합니다. Windows의 경로 정규화 전 이름과 실제 이름도 비교합니다. 파일은 CRC/해시만 검사하며 디스크에 압축 해제하거나 XML을 실행/외부 참조하지 않습니다.
- 원문 확보는 의미/효력 확정이 아닙니다. 목록·공시 수집 저널을 수정하지 않으며 원문 보관 폴더에 `effectiveEventConfirmed=false`를 남깁니다. 원문 audit는 인증정보·네트워크 없이 실행합니다.

## 실행

```powershell
# AI/ai-server. plan은 네트워크 없이 일봉/범위 기록을 감사합니다.
.\.venv\Scripts\python.exe -m app.replay.dart_history plan --history-job research-artifacts/history-job --local-use research-artifacts/local-use.json --corp-code 00126380 --output research-artifacts/dart-job --max-requests 12

# 기존 환경변수의 OpenDART enabled/API key가 설정된 경우에만 네트워크 수집합니다.
.\.venv\Scripts\python.exe -m app.replay.dart_history collect --job research-artifacts/dart-job
.\.venv\Scripts\python.exe -m app.replay.dart_history audit --job research-artifacts/dart-job

# 감사된 목록에서 명시적으로 선택한 원문 1건. output은 새 전용 폴더입니다.
.\.venv\Scripts\python.exe -m app.replay.dart_documents capture --index research-artifacts/dart-job --receipt 20241031000508 --output research-artifacts/dart-original
.\.venv\Scripts\python.exe -m app.replay.dart_documents audit --capture research-artifacts/dart-original
```

완료는 종료값 0, 미완료 audit는 1, 입력/파일/조회/무결성 오류는 고정 코드와 2입니다. 같은 완료 목록을 collect해도 새 요청을 보내지 않습니다. 실행 예시의 법인번호/접수번호는 대상 종목과 실제 수집 목록에 맞아야 합니다.
