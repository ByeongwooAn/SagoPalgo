# H01 폐지일·발행회사 관계·상장 종목 수 대조

2023-11-01~2026-11-02 KOSPI·KOSDAQ의 1,098일 목록과 [V7 관찰·공시 원장](remaining-membership-disclosures.md)을 기준으로 검증했습니다. 개별 공시의 효력·상장일, 공급자가 반환한 목록의 기준일, 자료 확보 시각을 구분해 보존합니다.

두 회사의 코스닥 보통주를 별도로 연결했습니다. 소멸회사 위지윅스튜디오는 `299900 / KR7299900001`, 존속회사 엔피·컴투스엔은 `291230 / KR7291230001`입니다. 존속회사 이름이 8월 14일 목록에서 바뀔 때 단축코드와 ISIN은 같았습니다. 8월 17일은 휴장으로 기록돼 있으나 KRX가 8월 18일을 현황 날짜로 표시한 처리 근거는 확보하지 못했습니다. 두 날짜의 출처를 보존하고 V7의 검토 1건을 유지합니다.

폐지 공지를 다시 가져오자 HTML 바이트 해시는 V7과 달랐습니다. 같은 접수번호·문서 경로의 이전 원문도 검증했고, 정규화한 본문이 같아 두 해시를 별도로 남겼습니다. 존속회사 반기보고서의 등기·효력일은 회사가 공시한 결과이며 등기부 원문과의 별도 대조는 남아 있습니다.

## 주식·발행회사 식별 범위

- **기간 전체 관찰**에서 보통주 ISIN 2,873개를 전체 단축코드·시장·관찰 이름으로 연결해 연속 관찰 구간 3,164개로 나눴습니다. 시장·이름·코드가 바뀌거나 관찰이 끊기면 구간을 분리합니다.
- **당시 개별 공시의 발행회사 이름**은 ISIN 557개에 연결했습니다. 공시의 전체 코드·시장과 V7의 관찰 ISIN이 맞는 근거를 사용합니다. 남은 2,316개는 그 방식의 개별 공시 연결이 미확인입니다. 짧은 KIND 발행회사 키나 이름만으로 종목을 연결하지 않습니다.
- **기간 끝인 2026-11-02의 별도 대조**에서 보통주 2,655개 중 **2,278개**의 전체 코드와 정규화 이름이 이후 확보한 OpenDART 고유번호 목록과 일치했습니다. KOSPI 725/829개, KOSDAQ 1,553/1,826개입니다. 이름이 다른 377개는 고유번호 연결을 보류했습니다. 이 대조에서 시장은 KRX 목록에서 가져오며 OpenDART 캡처의 취득일을 과거 상장 관계로 소급하지 않습니다. 개별 공시 557개와 중복될 수 있어 합산하지 않습니다. [OpenDART 고유번호 명세](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS001&apiId=2019018)

## 날짜별 종목 수와 별도 대조 범위

| 자료 | 시장별 대조 결과 | 해석 |
|---|---:|---|
| KRX 종목기본정보 | 1,098일 | 전체 종목 수와 보통주 수를 날짜·시장별로 별도 집계 |
| KRX 일별매매정보 | 9/9일 일치 | 2023-11-01 기존 표본과 신규 8거래일. 전체 행 수와 단축코드 집합 모두 대조 |
| KOSIS 상장주식 총괄 | 35/35개월 일치 | 2023-11~2026-09 공표 종목 수를 해당 달의 말일 목록과 대조. 회사 수는 별도 저장 |
| 다른 산출기관의 전체 일별 보통주 총수 | 확인된 날짜 0일 | 전 기간 독립 검증 미확인 |

별도 대조를 확보한 날짜는 두 범위를 합쳐 시장마다 **44일**입니다. KOSIS는 별도 공표 경로이며 통계 작성기관은 KRX입니다. 보통주만의 총수는 KOSIS 표의 공표 항목과 구분합니다. KRX 일별매매정보도 같은 공급자의 다른 API입니다. 두 대조에서 불일치는 0건이며 나머지 날짜를 앞뒤 값으로 채우지 않습니다. KRX 정보데이터시스템의 일별 종합정보 조회는 로그인 필요 응답을 확인해 추가 조회를 중단했습니다. [KOSPI 공표표](https://kosis.kr/statHtml/statHtml.do?orgId=343&tblId=DT_343_2010_S0013) · [KOSDAQ 공표표](https://kosis.kr/statHtml/statHtml.do?orgId=343&tblId=DT_343_2010_S0054) · [KRX 일별 종합정보](https://data.krx.co.kr/contents/MDC/MDI/outerLoader/index.cmd?screenId=MDCEASY002)

예를 들어 2026-08-14와 08-18의 KOSDAQ 전체 수는 둘 다 1,821개입니다. 두 날짜 사이에 위지윅스튜디오 `299900`이 제외되고 인제니아테라퓨틱스 `950260`이 들어왔습니다. 총수가 같을 때도 날짜별 종목 집합을 별도로 검사합니다.

## 재현과 검증

새 근거는 KIND 공시 5개의 뷰어·경로·본문 15개 응답, KOSIS 공개 표 조회 2개, KRX 일별매매정보 16회와 OpenDART 고유번호 1회입니다. KRX 호출은 기존 공유 일일 예산에 예약하고 시작 간격 1초를 적용했습니다. 공개 검색·자료 탐색 요청은 이 정식 증거 집계에서 제외합니다. 원문과 전체 결과는 Git 제외 경로에 보관합니다. [고정 입력 해시](../../examples/membership-identity-audit.json)

`AI/ai-server`에서 아래 명령으로 기존 로컬 자료를 대조합니다. `build`는 새 결과를 만들고, `audit`은 저장한 결과와 재계산 값을 비교합니다.

```powershell
$job = 'research-artifacts/historical-membership-identity-20261107'
$h01 = @(
  '--manifest', '../../docs/examples/membership-identity-audit.json',
  '--history', 'research-artifacts/krx-history-20231101-20261102-20261104/derived',
  '--v7', 'research-artifacts/remaining-membership-20261105/reconciled-v7.json',
  '--baseline-daily', 'research-artifacts/krx-daily-check-20231101-20261104',
  '--job', $job, '--output', "$job/report-final.json"
)
.\.venv\Scripts\python.exe -m app.replay.membership_identity_audit build @h01
.\.venv\Scripts\python.exe -m app.replay.membership_identity_audit audit @h01
```

네트워크를 차단한 재실행에서 보고서가 바이트 단위로 일치했고, V7과 일별 스냅샷을 포함한 입력 1,165개의 해시를 보존했습니다. 신규 10건을 포함한 관련 테스트 129건과 AI 서버 전체 1,356건이 통과했습니다. 실패·오류·제외는 0건입니다.

개별 공시 확인 **576/577**, 고정 체크리스트 **27/48 · 56%**, 5번 **7/18 · 39%**, **5-08 진행 중**을 유지합니다. H01에는 폐지 현황 날짜 차이의 원인, 나머지 과거 발행회사 식별, 같은 범위의 전 기간 독립 일별 총수 근거가 남았습니다. [남은 실행 단위](../../project/remaining-development-units.md)
