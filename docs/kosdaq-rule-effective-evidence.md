# 5-08 코스닥 과거 전문·위임 시행일 검증과 규정 V2

기준일: 2026-11-05. [과거 일반 정규장 규정 V1](historical-ordinary-session-rules.md)에서 남았던 **코스닥 제53차·제2280호의 전문/시행일**을 보강했습니다. 고정 범위는 2023-11-01~2026-11-02 KRX KOSPI·KOSDAQ 보통주입니다.

## 공식 근거를 연결한 방법

KRX [법무포털](https://rule.krx.co.kr/out/index.do)의 공개 본문 조회 양식은 과거 판본 선택 필드를 지원합니다. `POST https://rule.krx.co.kr/out/regulation/regulationViewPop.do`에 다음 필드를 지정했습니다.

| 근거 | bookid | oldyn | 본문 식별 |
|---|---|---|---|
| 코스닥 업무규정 과거 전문 | 210016900 | **Y** | 제53차·제2280호·2025-02-05 개정 |
| 당시 시행세칙 전문 | 210019594 | **Y** | 제111차·제2304호·2025-02-27 개정·2025-03-04 시행 |
| 후속 시행세칙의 같은 부칙 | 230001398 | 기본 현재 조회 | 제119차·제2500호·2026-09-10 개정·2026-09-14 시행 |

모두 `noformyn=N`을 사용합니다. 과거 전문에 `oldyn=Y`를 명시하자 제53차 제목·규정 번호·개정 차수·본문 조항의 판본 ID가 일치했습니다. 앞서 기본 요청으로 확보한 제52차 반환 기록은 잘못된 본문 반환의 관측으로 그대로 보존합니다. 조회 경로만 바꾼 추가 탐색도 제52차를 반환했으며 정식 근거로 채택하지 않았습니다.

제53차 전문의 시행일 헤더는 여전히 **9999-12-31**입니다. 이를 날짜로 변환하거나 원문을 고치지 않고 다음의 명시적 위임을 연결합니다.

1. **제2280호 자체 부칙**: 전산프로그램 개발 기간 등을 고려해 시행세칙으로 정하는 날부터 시행하도록 위임합니다.
2. **제2304호 시행세칙 부칙 제2조**: 제2280호와 그 개정일 **2025-02-05**를 특정하고 그 시행일을 **2025-03-04**로 정합니다. 같은 부칙 제1조의 시행세칙 시행일도 일치합니다.
3. **후속 제2500호 판본**: 같은 제2304호 부칙이 동일한 내용을 보존하는지 다시 대조합니다.

검사 대상 부칙의 규정 번호·공포일·위임 대상 규정 번호/개정일·정확한 시행 날짜를 모두 확인합니다. 다른 규정의 부칙, 목차, 다른 날짜, 조건부 문구 또는 중복된 후보로는 해결 처리하지 않습니다. 본문에 삽입된 참조 링크의 공백만 정규화하고 검토하지 않은 문장은 거절합니다.

원문의 `expected.effectiveDate`와 `observed.effectiveDate`는 **9999-12-31을 보존**하며, `resolvedEffectiveDate=2025-03-04`와 `effectiveDateBasis=ARCHIVED_RULE_AND_DELEGATING_BYLAW_APPENDIX`를 별도 기록합니다. V1의 두 진단은 같은 1건의 이전 관측으로 `resolvedPriorIssueCounts`에 보존하고, V2에는 해결된 날짜 근거와 `EFFECTIVE_DATE_PLACEHOLDER_PRESERVED` 경고를 함께 기록합니다.

제53·54차는 실제 시행일이 모두 2025-03-04이므로 하나의 기간 경계에 **두 판본 ID**를 보존합니다. KOSDAQ 구간은 2023-11-01~2025-03-03, 2025-03-04~2026-01-28, 2026-01-29~04-26, 04-27~07-01, 07-02~09-13, 09-14~11-02입니다. 정규장 명목 시간은 모두 09:00~15:30이며 종가 결정 연장·장중 정지·임시 시간 변경과 구분합니다.

## 다음 임시 변경 대조 범위

V2의 `temporaryChangeReviewPlan`을 **시장 2개 × 연도 4개 = 8구간**으로 생성했습니다. 각 행은 양 시장에서 각각 검사합니다.

| 적용 날짜 범위 | 시장별 일반 후보 | 시장별 기존 확인 특수 날짜 | 현재 상태 |
|---|---:|---|---|
| 2023-11-01~12-31 | 40일 | 2023-11-16 | PENDING |
| 2024-01-01~12-31 | 242일 | 2024-01-02, 2024-11-14 | PENDING |
| 2025-01-01~12-31 | 240일 | 2025-01-02, 2025-11-13 | PENDING |
| 2026-01-01~11-02 | 202일 | 2026-01-02 | PENDING |

이 표는 검토 계획이며 목록 수집·완전성 검증 결과가 아닙니다. 각 구간의 목록 완전성·페이지 범위·정정 계보 플래그는 모두 false입니다. 공지의 **적용일**을 위 범위에 연결하고, 선행 발표나 후행 정정이 적용일 밖에 발표될 가능성도 포함해 목록 검색 범위를 정해야 합니다. 기존 연초·수능일만으로 모든 변경을 확인했다고 판단하지 않습니다. 장중 시장 정지/재개와 개별 종목 거래정지는 정규장 예정 시간 변경과 별도로 처리합니다.

다음 개발에서는 공식 목록의 검색 조건·페이지 누락·정정/대체 공지·시장·실제 적용일을 검증한 뒤 해당 날짜만 실제 세션으로 확정해야 합니다. 규정 확인만으로 일반 후보를 일괄 승격하지 않습니다.

## 구현·수집·재현

`app.replay.rule_effective_evidence`에 capture/build/audit/as-of를 추가했습니다. [검토 설정](examples/kosdaq-rule-effective-evidence.json)은 **이전 규정 V1 보고서 해시**와 세 원문의 기대 식별값을 고정합니다. V1 보고서·기존 달력·ReferencePack·V7 종목군은 수정하지 않는 별도 V2입니다.

수집은 공개 화면의 일반 양식이며 로그인·계좌 인증키를 사용하지 않습니다. 요청 예산 사전 검사, 최소 1초 시작 간격, 3MiB 응답 상한, 자동 리다이렉트 차단, 실패 예약의 자동 재시도 금지를 적용했습니다. 기존 성공 영수증을 seed로 재사용하고 실제 요청 필드와 확보 시각을 보존합니다. 기본 현재 조회에서 `oldyn`을 생략했다면 이를 명시적으로 전송한 것처럼 기록하지 않습니다. 공개 양식 nonce·쿠키는 영수증이나 로그에 출력하지 않습니다.

이번 새 공개 HTTP는 **5회**, 모두 HTTP 200입니다. 정식 근거는 이 중 3개 본문이며 나머지는 공개 양식 시작과 다른 조회 경로의 불일치 관측입니다. 정식 캐시에 영수증 3개를 재사용해 추가 요청은 0회입니다. KIS·KB 계좌·OpenDART·KRX 인증 API 호출은 없습니다. 웹 검색은 별도입니다. 빈 정식 캐시 수집 상한은 공개 양식 시작 1회 + 원문 3회 = **4회**입니다.

실행 위치는 `AI/ai-server`입니다. 기존 V1은 해당 문서의 audit 명령으로 먼저 검사합니다. build는 새로운 출력 경로에 한 번 실행하고 audit는 저장된 전체 V2와 재계산 결과를 비교합니다.

```powershell
$effectiveArgs = @(
  '--scope', '../../docs/examples/kosdaq-rule-effective-evidence.json',
  '--cache', 'research-artifacts/kosdaq-rule-effective-20261105/sources',
  '--parent', 'research-artifacts/session-rules-20261105/report.json',
  '--output', 'research-artifacts/kosdaq-rule-effective-20261105/report-v2.json'
)
.\.venv\Scripts\python.exe -m app.replay.rule_effective_evidence audit @effectiveArgs
.\.venv\Scripts\python.exe -m app.replay.rule_effective_evidence capture `
  --scope ../../docs/examples/kosdaq-rule-effective-evidence.json `
  --cache research-artifacts/kosdaq-rule-effective-20261105/sources --max-new-requests 0
```

원문·연구 산출물은 기존 정책대로 Git에서 제외합니다. 위 해시 그대로 재현하려면 기존 원문·영수증·부모 보고서가 필요합니다. 새 환경에서 재수집하면 확보 시각과 부모 해시가 달라지므로 기존 설정을 덮어쓰지 말고 검토를 거친 새 설정·보고서 버전으로 연결해야 합니다.

위임 시행일은 과거 공개 시각이 아닙니다. 새 KOSDAQ 규정 연결은 전문·당시 시행세칙·후속 대조본을 실제 확보한 이후에만 시점 조회로 노출하며, 기존 후보의 더 늦은 지식 시각도 보존합니다. 기존 KOSPI 조회 시점·실제 특수 세션·달력 근거는 보존합니다.
