# Python 분석·수집·검증

- 루트 공통 지침에 이 디렉터리의 규칙을 추가 적용한다.
- 관련 `app` 모듈·`tests`·주제별 `docs`부터 확인한다. 전체 수집·규정 이력을 매번 읽지 않는다.
- 기존 원문·캐시·영수증·해시·검토 결과와 수집·감사 CLI를 우선 사용한다. 목록·차이·충돌은 스크립트로 추출한다.
- 오프라인 재검증과 신규 수집을 구분한다. 새 근거가 필요한 미해결 범위만 조회하고 기존 수집 범위를 임의로 확장하지 않는다.
- 발표일·적용일·수집일·당시 가용 시점을 구분하고 원본·계보를 보존한다. 미확인 후보를 확정 사실이나 실제 세션으로 승격하지 않는다.
- 선택 범위 검토와 전체 완료, 데이터 확보와 거래·학습 가능 여부를 구분한다. 완료율은 명시된 조건을 충족할 때만 바꾼다.
- 분석 API와 연구용 재현 도구의 역할을 유지한다. 요청 없이 유료 AI 호출·실계좌·자동 주문을 활성화하지 않는다.
- 명령은 이 폴더에서 실행한다. Windows 가상환경 Python은 `.\.venv\Scripts\python.exe`이다.
- 개발 중 `python -m pytest -q tests/<관련 파일>`로 확인하고, Python 코드 변경 마무리에는 `python -m pytest -q`로 전체 회귀를 확인한다. `python`은 해당 가상환경 실행 파일로 대체한다.
- 원문·명세만 바뀌어도 파서·감사·시점 판정에 영향을 주면 관련 검증을 실행한다. 네트워크 수집을 테스트 대신 반복하지 않는다.
